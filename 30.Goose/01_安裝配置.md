## 🖥️ 系統要求

### 最低要求

- **作業系統**:
  - Linux (Ubuntu 20.04+, Debian 11+, Fedora 35+)
  - macOS (11.0+)
  - Windows (10/11 with WSL2)
- **Python**: 3.10 或更高版本
- **磁盤空間**: 至少 500 MB
- **RAM**: 建議 4 GB 以上
- **網絡**: 需要網絡連接（使用雲端模型時）

### 推薦配置

- **Python**: 3.11+
- **RAM**: 8 GB+
- **處理器**: 多核心處理器（用於本地模型）
- **GPU**: NVIDIA GPU（用於本地大型模型）

## 📦 安裝方法

### 方法 1: pipx（推薦）

**優點**: 隔離環境、全局可用、易於管理

```bash
# 1. 安裝 pipx（如果尚未安裝）
python3 -m pip install --user pipx
python3 -m pipx ensurepath

# 2. 重新加載 shell 配置
source ~/.bashrc  # 或 ~/.zshrc

# 3. 安裝 Goose
pipx install goose-ai

# 4. 驗證安裝
goose --version
# 輸出: goose 0.x.x
```

**升級**:
```bash
pipx upgrade goose-ai
```

**卸載**:
```bash
pipx uninstall goose-ai
```

---

### 方法 2: Homebrew（macOS/Linux）

**優點**: 系統包管理、自動更新、依賴處理

```bash
# 1. 安裝 Homebrew（如果尚未安裝）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. 添加 Block tap
brew tap block/tap

# 3. 安裝 Goose
brew install goose

# 4. 驗證安裝
goose --version
```

**升級**:
```bash
brew upgrade goose
```

**卸載**:
```bash
brew uninstall goose
```

---

### 方法 3: pip（虛擬環境）

**優點**: 完全控制、適合開發

```bash
# 1. 創建虛擬環境
python3 -m venv goose-env

# 2. 激活虛擬環境
# Linux/macOS:
source goose-env/bin/activate
# Windows:
goose-env\Scripts\activate

# 3. 安裝 Goose
pip install goose-ai

# 4. 驗證安裝
goose --version
```

**每次使用前需激活環境**:
```bash
source goose-env/bin/activate  # Linux/macOS
```

---

### 方法 4: 從源碼安裝（開發者）

**優點**: 最新功能、可修改源碼

```bash
# 1. 克隆倉庫
git clone https://github.com/block/goose.git
cd goose

# 2. 創建虛擬環境
python3 -m venv venv
source venv/bin/activate

# 3. 安裝依賴
pip install -e ".[dev]"

# 4. 驗證安裝
goose --version
```

## 🔧 初始配置

### 首次運行

```bash
# 初始化配置
goose init

# 輸出:
# ✓ 創建配置目錄: ~/.config/goose/
# ✓ 創建配置文件: config.yaml
# ✓ 創建會話目錄: sessions/
# ✓ 創建插件目錄: plugins/
```

### 配置文件位置

```
~/.config/goose/
├── config.yaml          # 主配置文件
├── sessions/            # 會話存儲
│   └── default/
├── plugins/             # 自定義插件
└── logs/                # 日誌文件
```

### 基本配置文件

```yaml
# ~/.config/goose/config.yaml

# LLM 提供商設置
provider:
  type: openai           # openai, anthropic, google, azure, ollama
  model: gpt-4-turbo-preview
  api_key: ${OPENAI_API_KEY}  # 從環境變量讀取
  temperature: 0.7
  max_tokens: 4096

# 工具設置
tools:
  enabled:
    - file_operations
    - shell_executor
    - git_operations
    - web_search
    - code_analyzer

  # 文件操作設置
  file_operations:
    allowed_extensions:
      - .py
      - .js
      - .ts
      - .java
      - .go
    max_file_size: 1048576  # 1MB

  # Shell 執行設置
  shell_executor:
    enabled: true
    timeout: 30  # 秒
    allowed_commands:
      - git
      - npm
      - pip
      - python
      - pytest

# 會話設置
session:
  auto_save: true
  save_interval: 60  # 秒
  max_history: 100   # 消息數量

# 日誌設置
logging:
  level: INFO  # DEBUG, INFO, WARNING, ERROR
  file: ~/.config/goose/logs/goose.log
  rotation: daily
  retention: 7  # 天

# UI 設置
ui:
  color: true
  emoji: true
  streaming: true

# 性能設置
performance:
  cache_enabled: true
  cache_ttl: 3600  # 秒
  parallel_tools: 3  # 並發工具數量
```

## 🔑 API Key 設置

### OpenAI

```bash
# 方法 1: 環境變量（臨時）
export OPENAI_API_KEY='sk-...'

# 方法 2: 添加到 shell 配置（永久）
echo 'export OPENAI_API_KEY="sk-..."' >> ~/.bashrc
source ~/.bashrc

# 方法 3: .env 文件
cat > ~/.config/goose/.env << 'EOF'
OPENAI_API_KEY=sk-...
EOF

# 方法 4: 直接設置到配置
goose config set provider.api_key "sk-..."
```

**獲取 API Key**:
1. 訪問 https://platform.openai.com/api-keys
2. 登錄或註冊
3. 創建新 API Key
4. 複製並保存（僅顯示一次）

### Anthropic Claude

```bash
# 設置 API Key
export ANTHROPIC_API_KEY='sk-ant-...'

# 配置使用 Claude
goose config set provider.type anthropic
goose config set provider.model claude-3-opus-20240229
```

**獲取 API Key**:
1. 訪問 https://console.anthropic.com/
2. 創建賬戶
3. 生成 API Key

### Google Gemini

```bash
# 設置 API Key
export GOOGLE_API_KEY='...'

# 配置
goose config set provider.type google
goose config set provider.model gemini-pro
```

### Azure OpenAI

```bash
# 設置多個環境變量
export AZURE_OPENAI_API_KEY='...'
export AZURE_OPENAI_ENDPOINT='https://your-resource.openai.azure.com/'
export AZURE_OPENAI_DEPLOYMENT='your-deployment-name'

# 配置
goose config set provider.type azure
```

### Ollama（本地模型）

```bash
# 1. 安裝 Ollama
curl -fsSL https://ollama.ai/install.sh | sh

# 2. 下載模型
ollama pull llama2
ollama pull codellama

# 3. 配置 Goose
goose config set provider.type ollama
goose config set provider.model llama2
goose config set provider.base_url http://localhost:11434
```

## ⚙️ 高級配置

### 項目特定配置

在項目根目錄創建 `.goose/config.yaml`:

```yaml
# .goose/config.yaml

project:
  name: my-awesome-app
  language: python
  framework: django
  version: "1.0.0"

# 項目風格指南
style:
  code_style: pep8
  max_line_length: 88
  indentation: 4
  quotes: double

# 測試配置
testing:
  framework: pytest
  coverage_threshold: 80
  test_directory: tests/

# 文檔配置
documentation:
  style: google  # google, numpy, sphinx
  auto_generate: true

# Git 配置
git:
  auto_commit: false
  commit_message_prefix: "[AI]"
  branch_prefix: "ai/"

# 權限設置
permissions:
  allow_file_write: true
  allow_file_delete: false
  allow_shell_exec: true
  allowed_directories:
    - src/
    - tests/
  blocked_files:
    - "*.env"
    - "secrets.*"
    - "credentials.*"
```

### 團隊共享配置

```yaml
# .goose/team.yaml

team:
  name: development-team

  # 共享規則
  rules:
    - name: "代碼審查"
      trigger: pull_request
      actions:
        - review_code
        - check_tests
        - check_coverage

    - name: "自動格式化"
      trigger: pre_commit
      actions:
        - format_code
        - lint_code

  # 工具偏好
  tools:
    formatter: black
    linter: ruff
    type_checker: mypy

  # 通知設置
  notifications:
    slack_webhook: ${SLACK_WEBHOOK_URL}
    email: team@example.com
```

### 自定義工具配置

```yaml
# ~/.config/goose/tools.yaml

custom_tools:
  - name: deploy_to_staging
    description: "部署到測試環境"
    command: "./scripts/deploy.sh staging"
    requires_confirmation: true

  - name: run_integration_tests
    description: "運行集成測試"
    command: "pytest tests/integration/"
    timeout: 300

  - name: generate_changelog
    description: "生成變更日誌"
    command: "git-cliff -o CHANGELOG.md"
```

## 🔍 故障排除

### 問題 1: 找不到 goose 命令

**症狀**: `command not found: goose`

**解決方案**:

```bash
# 檢查 PATH
echo $PATH

# 使用 pipx 時
pipx ensurepath
source ~/.bashrc

# 使用 pip 時
source goose-env/bin/activate
```

### 問題 2: API Key 無效

**症狀**: `Authentication failed` 或 `Invalid API key`

**解決方案**:

```bash
# 檢查環境變量
echo $OPENAI_API_KEY

# 驗證 API Key
curl https://api.openai.com/v1/models \
  -H "Authorization: Bearer $OPENAI_API_KEY"

# 重新設置
export OPENAI_API_KEY='your-valid-key'
```

### 問題 3: 權限錯誤

**症狀**: `Permission denied`

**解決方案**:

```bash
# 檢查配置目錄權限
ls -la ~/.config/goose/

# 修復權限
chmod -R 755 ~/.config/goose/
```

### 問題 4: 模型不可用

**症狀**: `Model not found` 或 `Model not available`

**解決方案**:

```bash
# 列出可用模型
goose models list

# 切換到可用模型
goose config set provider.model gpt-3.5-turbo
```

### 問題 5: 網絡連接問題

**症狀**: `Connection timeout` 或 `Network error`

**解決方案**:

```bash
# 檢查網絡
ping api.openai.com

# 設置代理
export HTTP_PROXY=http://proxy.example.com:8080
export HTTPS_PROXY=http://proxy.example.com:8080

# 或在配置中設置
goose config set network.proxy "http://proxy.example.com:8080"
```

## 🔄 升級和卸載

### 升級 Goose

```bash
# pipx
pipx upgrade goose-ai

# Homebrew
brew upgrade goose

# pip
pip install --upgrade goose-ai

# 從源碼
cd goose
git pull
pip install -e ".[dev]"
```

### 檢查版本

```bash
# 查看當前版本
goose --version

# 查看詳細信息
goose info
```

### 清理配置

```bash
# 備份配置
cp -r ~/.config/goose ~/.config/goose.backup

# 重置配置
goose config reset

# 清理緩存
goose cache clear

# 清理日誌
rm -rf ~/.config/goose/logs/*
```

### 完全卸載

```bash
# 1. 卸載程序
pipx uninstall goose-ai  # 或 brew uninstall goose

# 2. 刪除配置（可選）
rm -rf ~/.config/goose

# 3. 刪除緩存（可選）
rm -rf ~/.cache/goose

# 4. 清理環境變量（從 ~/.bashrc 移除）
# 移除這一行: export OPENAI_API_KEY="..."
```
