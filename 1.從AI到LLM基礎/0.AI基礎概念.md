## 什麼是人工智慧

### 定義

**人工智慧 (Artificial Intelligence, AI)** 是指由人類創造的系統所展現出的智慧能力,包括:

- 🧠 **學習能力**: 從經驗中獲取知識
- 🔍 **推理能力**: 使用邏輯進行推斷
- 🗣️ **理解能力**: 理解自然語言和圖像
- 🎯 **決策能力**: 在複雜環境中做出決策
- 🔄 **適應能力**: 適應新的情況和問題

### AI vs 傳統程式設計

| 特性 | 傳統程式設計 | AI 系統 |
|------|------------|---------|
| **邏輯** | 明確規則 | 從數據學習 |
| **靈活性** | 低 | 高 |
| **處理複雜性** | 有限 | 強大 |
| **可解釋性** | 高 | 低到中 |
| **數據需求** | 低 | 高 |

### 核心概念

```
傳統程式設計:
輸入 + 規則 → 輸出

機器學習:
輸入 + 輸出 → 規則 (模型)

AI 應用:
輸入 + 學習到的模型 → 預測/決策
```

## AI 發展歷史

### 🌟 重要里程碑

#### 1950s - 起源時代
- **1950**: 艾倫·圖靈提出「圖靈測試」
- **1956**: 達特茅斯會議,AI 正式誕生
- **1958**: 感知器 (Perceptron) 發明

#### 1960s-1970s - 第一次繁榮
- 專家系統發展
- LISP 語言誕生
- 早期自然語言處理

#### 1980s-1990s - AI 寒冬與復甦
- 專家系統商業化
- 神經網路理論發展
- 反向傳播算法

#### 2000s - 機器學習時代
- **2006**: 深度學習概念提出
- **2009**: ImageNet 數據集發布
- **2011**: IBM Watson 贏得 Jeopardy!

#### 2010s - 深度學習革命
- **2012**: AlexNet 贏得 ImageNet 競賽
- **2014**: GAN (生成對抗網路) 提出
- **2016**: AlphaGo 擊敗李世乭
- **2017**: Transformer 架構發表

#### 2020s - LLM 時代
- **2020**: GPT-3 發布 (175B 參數)
- **2022**: ChatGPT 爆紅
- **2023**: GPT-4, Claude, Gemini 等多模態模型
- **2024**: 開源 LLM 蓬勃發展
- **2025**: AI Agent 成為主流應用

### 📈 技術發展趨勢圖

```
1950s ▶ 符號主義 AI
   ↓
1980s ▶ 專家系統
   ↓
1990s ▶ 機器學習
   ↓
2010s ▶ 深度學習
   ↓
2020s ▶ 大型語言模型 (LLM)
   ↓

```

## AI 的分類

### 按能力分類

#### 1. 弱人工智慧 (Narrow AI / ANI)
- **定義**: 專注於特定任務的 AI
- **特點**:
  - 在特定領域表現優異
  - 無法遷移到其他領域
  - 目前絕大多數 AI 都屬於此類
- **例子**:
  - 語音助手 (Siri, Alexa)
  - 圖像識別系統
  - 推薦系統
  - 下棋程式

#### 2. 強人工智慧 (General AI / AGI)
- **定義**: 具有人類級別智能的 AI
- **特點**:
  - 可以理解、學習任何智力任務
  - 具有遷移學習能力
  - 目前尚未實現
- **目標**:
  - 像人類一樣思考
  - 解決各種問題
  - 自主學習和適應

#### 3. 超人工智慧 (Super AI / ASI)
- **定義**: 超越人類智能的 AI
- **特點**:
  - 在所有領域都超越人類
  - 理論階段
  - 引發倫理和安全討論

### 按技術分類

#### 1. 規則基礎系統 (Rule-Based)
```python
# 簡單規則範例
if temperature > 30:
    recommendation = "開冷氣"
elif temperature < 15:
    recommendation = "開暖氣"
else:
    recommendation = "保持現狀"
```

#### 2. 機器學習系統 (Machine Learning)
- 監督式學習
- 非監督式學習
- 強化學習

#### 3. 深度學習系統 (Deep Learning)
- 神經網路
- 卷積神經網路 (CNN)
- 循環神經網路 (RNN)
- Transformer

#### 4. 符號 AI (Symbolic AI)
- 知識圖譜
- 邏輯推理
- 專家系統

## AI 的核心技術

### 1. 機器學習 (Machine Learning)

**核心概念**: 讓機器從數據中自動學習模式

#### 主要類型

##### 監督式學習 (Supervised Learning)
```
訓練數據: (輸入, 正確答案) 配對
目標: 學習輸入到輸出的映射關係

應用例子:
- 圖像分類 (貓 vs 狗)
- 垃圾郵件偵測
- 房價預測
```

##### 非監督式學習 (Unsupervised Learning)
```
訓練數據: 只有輸入,沒有標籤
目標: 發現數據中的隱藏模式

應用例子:
- 客戶分群
- 異常偵測
- 降維
```

##### 強化學習 (Reinforcement Learning)
```
訓練方式: 通過獎勵和懲罰學習
目標: 學習在環境中採取最優行動

應用例子:
- 遊戲 AI (AlphaGo)
- 機器人控制
- 自動駕駛
```

### 2. 深度學習 (Deep Learning)

**核心概念**: 使用多層神經網路學習數據的層次化表示

#### 基本架構

```
輸入層 → 隱藏層1 → 隱藏層2 → ... → 輸出層
   ↓         ↓          ↓              ↓
  像素     邊緣特徵   形狀特徵      物體類別
```

#### 關鍵技術

1. **反向傳播 (Backpropagation)**
   - 計算梯度
   - 更新權重
   - 最小化損失函數

2. **激活函數 (Activation Functions)**
   - ReLU: `f(x) = max(0, x)`
   - Sigmoid: `f(x) = 1 / (1 + e^-x)`
   - Tanh: `f(x) = (e^x - e^-x) / (e^x + e^-x)`

3. **正則化 (Regularization)**
   - Dropout
   - L1/L2 正則化
   - Batch Normalization

### 3. 自然語言處理 (NLP)

**核心概念**: 讓機器理解和生成人類語言

#### 關鍵技術

1. **詞嵌入 (Word Embeddings)**
   - Word2Vec
   - GloVe
   - FastText

2. **序列模型**
   - RNN (循環神經網路)
   - LSTM (長短期記憶網路)
   - GRU (門控循環單元)

3. **注意力機制 (Attention)**
   - Self-Attention
   - Multi-Head Attention
   - Cross-Attention

4. **Transformer**
   - BERT
   - GPT
   - T5

### 4. 電腦視覺 (Computer Vision)

**核心概念**: 讓機器理解視覺信息

#### 關鍵技術

1. **卷積神經網路 (CNN)**
   - 卷積層 (Convolution)
   - 池化層 (Pooling)
   - 全連接層 (Fully Connected)

2. **物體偵測**
   - R-CNN 系列
   - YOLO
   - SSD

3. **圖像分割**
   - FCN
   - U-Net
   - Mask R-CNN

4. **生成模型**
   - GAN
   - VAE
   - Diffusion Models

## AI 的未來趨勢

### 1. 技術趨勢

#### 大型語言模型 (LLM)
- **多模態整合**: 文字、圖像、音訊、視訊
- **模型效率**: 更小、更快、更省資源
- **開源生態**: Llama, Mistral, Gemma

#### AI Agent
- **自主規劃**: 複雜任務分解
- **工具使用**: Function Calling
- **多 Agent 協作**: AutoGen, CrewAI

#### 邊緣 AI
- **設備端運行**: 手機、IoT 裝置
- **低延遲**: 即時處理
- **隱私保護**: 數據本地處理

### 2. 應用趨勢

#### 個性化 AI 助手
- 根據個人習慣定制
- 跨平台整合
- 主動式服務

#### AI 在創意產業
- 藝術創作輔助
- 音樂生成
- 影片製作

#### AI 在科學研究
- 蛋白質結構預測 (AlphaFold)
