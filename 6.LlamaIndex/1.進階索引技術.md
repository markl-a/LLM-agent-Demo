## 1. 樹形索引 (Tree Index)

樹形索引通過自下而上的總結構建索引樹，適合需要層次化信息組織的場景。

### 基本使用

```python
from llama_index.core import VectorStoreIndex, TreeIndex, SimpleDirectoryReader
from llama_index.core.node_parser import SentenceSplitter

# 加載文檔
documents = SimpleDirectoryReader("data").load_data()

# 創建樹形索引
tree_index = TreeIndex.from_documents(
    documents,
    num_children=10,  # 每個父節點的子節點數
    build_tree=True
)

# 查詢
query_engine = tree_index.as_query_engine(
    child_branch_factor=2  # 查詢時探索的分支數
)

response = query_engine.query("什麼是機器學習？")
print(response)
```

### 使用場景

- **階層性文檔**: 如組織架構、產品目錄
- **長文檔**: 需要先總覽再深入細節
- **多層次查詢**: 需要在不同抽象層次回答問題

### 優缺點

**優點**:
- 支持多層次查詢
- 可以從高層次總覽到細節
- 適合結構化文檔

**缺點**:
- 構建時間較長
- 對扁平文檔效果一般
- 查詢速度可能較慢

## 2. 關鍵詞索引 (Keyword Table Index)

基於關鍵詞的索引，通過提取關鍵詞進行快速匹配。

### 基本使用

```python
from llama_index.core import KeywordTableIndex

# 創建關鍵詞索引
keyword_index = KeywordTableIndex.from_documents(
    documents,
    max_keywords_per_chunk=10  # 每個文檔塊提取的最大關鍵詞數
)

# 查詢
query_engine = keyword_index.as_query_engine()
response = query_engine.query("Python 程式設計")
```

### 進階：自定義關鍵詞提取

```python
from llama_index.core.extractors import KeywordExtractor

# 自定義關鍵詞提取器
keyword_extractor = KeywordExtractor(
    keywords=10,  # 提取的關鍵詞數量
    llm=llm  # 使用 LLM 提取關鍵詞
)

# 提取關鍵詞
nodes = keyword_extractor.extract(documents)

# 創建索引
keyword_index = KeywordTableIndex(nodes)
```

### 使用場景

- **精確匹配查詢**: 已知關鍵詞
- **多關鍵詞搜索**: 需要同時匹配多個關鍵詞
- **快速過濾**: 預過濾大量文檔

## 3. 分層索引 (Hierarchical Index)

組合多個索引，先用簡單索引過濾，再用複雜索引精確查詢。

### 基本實現

```python
from llama_index.core import VectorStoreIndex, SummaryIndex
from llama_index.core.tools import QueryEngineTool
from llama_index.core.query_engine import RouterQueryEngine
from llama_index.core.selectors import PydanticSingleSelector

# 創建多個索引
vector_index = VectorStoreIndex.from_documents(documents)
summary_index = SummaryIndex.from_documents(documents)

# 創建查詢引擎工具
vector_tool = QueryEngineTool.from_defaults(
    query_engine=vector_index.as_query_engine(),
    description="用於語義搜索和相似度查詢"
)

summary_tool = QueryEngineTool.from_defaults(
    query_engine=summary_index.as_query_engine(),
    description="用於總結性查詢"
)

# 創建路由查詢引擎
router_query_engine = RouterQueryEngine(
    selector=PydanticSingleSelector.from_defaults(),
    query_engine_tools=[vector_tool, summary_tool]
)

# 查詢（自動選擇最合適的索引）
response = router_query_engine.query("總結所有文檔的主要內容")
```

### 進階：圖索引 + 向量索引

```python
from llama_index.core import KnowledgeGraphIndex

# 創建知識圖譜索引
kg_index = KnowledgeGraphIndex.from_documents(
    documents,
    max_triplets_per_chunk=10,
    include_embeddings=True  # 同時包含向量嵌入
)

# 結合向量索引
hybrid_query_engine = kg_index.as_query_engine(
    include_text=True,  # 包含原文檢索
    response_mode="tree_summarize"  # 使用樹形總結
)

response = hybrid_query_engine.query("深度學習和神經網絡的關係")
```

## 4. 文檔摘要索引優化

### 多級摘要

```python
from llama_index.core import Document
from llama_index.core.node_parser import SentenceSplitter
from llama_index.core.extractors import SummaryExtractor

# 創建摘要提取器
summary_extractor = SummaryExtractor(
    summaries=["self", "prev", "next"],  # 提取自身、前一段、後一段的摘要
    llm=llm
)

# 分割文檔
splitter = SentenceSplitter(chunk_size=1024)
nodes = splitter.get_nodes_from_documents(documents)

# 提取摘要
nodes = summary_extractor.extract(nodes)

# 創建索引
index = VectorStoreIndex(nodes)
```

### 查詢時動態摘要

```python
from llama_index.core.query_engine import CitationQueryEngine

# 創建引用查詢引擎
query_engine = CitationQueryEngine.from_args(
    index,
    similarity_top_k=3,
    citation_chunk_size=512  # 引用片段大小
)

response = query_engine.query("什麼是 Transformer?")

# 輸出會包含來源引用
print(response)
print("\n來源:")
for node in response.source_nodes:
    print(f"- {node.node.metadata}")
```

## 5. 向量存儲優化

### 使用專業向量數據庫

```python
import chromadb
from llama_index.vector_stores.chroma import ChromaVectorStore
from llama_index.core import StorageContext

# 創建 Chroma 客戶端
chroma_client = chromadb.PersistentClient(path="./chroma_db")
chroma_collection = chroma_client.create_collection("my_collection")

# 創建向量存儲
vector_store = ChromaVectorStore(chroma_collection=chroma_collection)
storage_context = StorageContext.from_defaults(vector_store=vector_store)

# 創建索引
index = VectorStoreIndex.from_documents(
    documents,
    storage_context=storage_context
)

# 持久化（Chroma 自動持久化）
# 下次可以直接加載
index = VectorStoreIndex.from_vector_store(
    vector_store=vector_store
)
```

### 使用 Pinecone（生產環境推薦）

```python
import pinecone
from llama_index.vector_stores.pinecone import PineconeVectorStore

# 初始化 Pinecone
pinecone.init(
    api_key="your-api-key",
    environment="your-environment"
)

# 創建或連接索引
if "my-index" not in pinecone.list_indexes():
    pinecone.create_index(
        "my-index",
        dimension=1536,  # OpenAI embedding 維度
        metric="cosine"
    )

# 創建向量存儲
vector_store = PineconeVectorStore(
    pinecone_index=pinecone.Index("my-index")
)

storage_context = StorageContext.from_defaults(vector_store=vector_store)

# 創建索引
index = VectorStoreIndex.from_documents(
    documents,
    storage_context=storage_context
)
```

## 6. 索引性能優化

### 批量處理

```python
from llama_index.core.ingestion import IngestionPipeline
from llama_index.core.extractors import TitleExtractor

# 創建數據處理管道
pipeline = IngestionPipeline(
    transformations=[
        SentenceSplitter(chunk_size=1024, chunk_overlap=20),
        TitleExtractor(),
        embeddings_model  # 嵌入模型
    ]
)

# 批量處理文檔
nodes = pipeline.run(documents=documents)

# 創建索引
index = VectorStoreIndex(nodes)
```

### 增量更新

```python
# 插入新文檔
new_documents = SimpleDirectoryReader("new_data").load_data()

for doc in new_documents:
    index.insert(doc)

# 更新文檔
index.update_ref_doc(
    document=updated_doc,
    update_kwargs={"delete": True}  # 先刪除舊的
)

# 刪除文檔
index.delete_ref_doc(
    ref_doc_id="doc_id",
    delete_from_docstore=True

```

### 並行處理

```python
from concurrent.futures import ThreadPoolExecutor
import asyncio

async def async_embed_documents(documents):
    """異步嵌入文檔"""
    tasks = []
    for doc in documents:
        task = asyncio.create_task(embeddings_model.aget_text_embedding(doc.text))
        tasks.append(task)

    embeddings = await asyncio.gather(*tasks)
    return embeddings

# 使用異步處理
embeddings = asyncio.run(async_embed_documents(documents))
```

## 7. 實際應用案例

### 案例1：多語言文檔檢索

```python
from llama_index.core.indices.multi_modal import MultiModalVectorStoreIndex
from llama_index.embeddings.openai import OpenAIEmbedding

# 使用多語言 embedding
multilingual_embed = OpenAIEmbedding(
    model="text-embedding-3-large"  # 支持多語言
)

# 創建索引
index = VectorStoreIndex.from_documents(
    documents,
    embed_model=multilingual_embed
)

# 可以用中文查詢英文文檔，反之亦然
response = index.as_query_engine().query("What is artificial intelligence?")
```

### 案例2：大規模文檔集合

```python
from llama_index.core import SimpleDirectoryReader
from llama_index.core.node_parser import SimpleNodeParser

# 分批加載大量文檔
def load_documents_in_batches(directory, batch_size=100):
    reader = SimpleDirectoryReader(directory)
    all_docs = reader.load_data()

    for i in range(0, len(all_docs), batch_size):
        yield all_docs[i:i+batch_size]

# 分批構建索引
for batch in load_documents_in_batches("large_dataset"):
    # 處理批次
    nodes = node_parser.get_nodes_from_documents(batch)

    # 添加到索引
    for node in nodes:
        index.insert_nodes([node])

    print(f"已處理 {len(batch)} 個文檔")
```

### 案例3：混合檢索策略

```python
from llama_index.core.retrievers import VectorIndexRetriever, KeywordTableSimpleRetriever
from llama_index.core.query_engine import RetrieverQueryEngine
from llama_index.core import QueryBundle

# 創建兩種檢索器
vector_retriever = VectorIndexRetriever(
    index=vector_index,
    similarity_top_k=5
)

keyword_retriever = KeywordTableSimpleRetriever(
    index=keyword_index
)

# 自定義混合檢索
class HybridRetriever:
    def __init__(self, vector_retriever, keyword_retriever):
        self.vector_retriever = vector_retriever
        self.keyword_retriever = keyword_retriever

    def retrieve(self, query_bundle: QueryBundle):
        # 獲取兩種檢索結果
        vector_nodes = self.vector_retriever.retrieve(query_bundle)
        keyword_nodes = self.keyword_retriever.retrieve(query_bundle)

        # 合併並去重
        all_nodes = vector_nodes + keyword_nodes
        unique_nodes = {node.node_id: node for node in all_nodes}.values()

        # 重新排序（可以根據分數）
        sorted_nodes = sorted(
            unique_nodes,
            key=lambda x: x.score if hasattr(x, 'score') else 0,
            reverse=True
        )

        return sorted_nodes[:10]  # 返回前10個

# 使用混合檢索器
hybrid_retriever = HybridRetriever(vector_retriever, keyword_retriever)
query_engine = RetrieverQueryEngine(retriever=hybrid_retriever)

response = query_engine.query("Python 機器學習庫")
```

## 8. 最佳實踐總結

### 索引選擇指南

| 場景 | 推薦索引 | 原因 |
|------|---------|------|
| 一般問答 | VectorStoreIndex | 平衡性能和準確性 |
| 長文檔 | TreeIndex | 層次化組織 |
| 精確匹配 | KeywordTableIndex | 快速關鍵詞查找 |
| 關係查詢 | KnowledgeGraphIndex | 理解實體關係 |
| 總結性問題 | SummaryIndex | 全文檔掃描 |
| 混合查詢 | 組合多種索引 | 發揮各自優勢 |

### 性能優化清單

- [ ] 使用專業向量數據庫（Pinecone, Chroma）
- [ ] 實現增量更新而非全量重建
- [ ] 合理設置 chunk_size 和 chunk_overlap
- [ ] 使用批量處理和異步操作
- [ ] 實現結果緩存
- [ ] 監控索引大小和查詢延遲
- [ ] 定期清理和優化索引

### 生產環境建議

1. **監控和日誌**: 記錄查詢性能、錯誤率
2. **備份策略**: 定期備份索引數據
3. **版本控制**: 為索引結構變更做版本管理
4. **A/B 測試**: 測試不同索引配置的效果
5. **成本優化**: 選擇合適的 embedding 模型和向量數據庫
