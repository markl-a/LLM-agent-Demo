## Transformer 簡介

### 歷史背景

**論文**: "Attention Is All You Need" (2017, Google)

**革命性突破**:
- ❌ 拋棄 RNN/LSTM 的順序處理
- ✅ 純注意力機制
- ✅ 並行計算
- ✅ 處理長距離依賴

### 為什麼需要 Transformer?

#### RNN/LSTM 的問題

```
RNN 處理序列 "我 愛 自然 語言 處理":

時間步 1: 我      →  h1
時間步 2: 我 愛    →  h2
時間步 3: 我 愛 自然 →  h3
...

問題:
1. ❌ 必須順序處理,無法並行
2. ❌ 長距離依賴困難
3. ❌ 梯度消失/爆炸
```

#### Transformer 的優勢

```
Transformer 處理同樣序列:

所有詞同時處理 ✅
任意位置可以直接交互 ✅
完全並行計算 ✅
```

### 應用範圍

- 🗣️ **NLP**: GPT, BERT, T5
- 🖼️ **視覺**: ViT, DALL-E
- 🎵 **音訊**: Whisper, MusicGen
- 🧬 **生物**: AlphaFold
- 🎮 **多模態**: GPT-4, Gemini

## 核心機制

### 1. Self-Attention (自注意力)

#### 核心思想

**讓序列中的每個位置關注其他所有位置**

```
輸入句子: "The cat sat on the mat"

處理 "cat" 時:
- 關注 "The" (10%)
- 關注 "cat" (30%)  ← 自己
- 關注 "sat" (40%)
- 關注 "on"  (5%)
- 關注 "the" (5%)
- 關注 "mat" (10%)
```

#### 數學公式

```
Attention(Q, K, V) = softmax(Q×K^T / √d_k) × V

Q: Query (查詢)
K: Key (鍵)
V: Value (值)
d_k: Key 的維度
```

#### 詳細步驟

**步驟 1: 生成 Q, K, V**

```python
# 輸入: X (batch_size, seq_len, d_model)
Q = X @ W_Q  # (batch_size, seq_len, d_k)
K = X @ W_K  # (batch_size, seq_len, d_k)
V = X @ W_V  # (batch_size, seq_len, d_v)
```

**步驟 2: 計算注意力分數**

```python
# 計算相似度
scores = Q @ K.transpose(-2, -1)  # (batch_size, seq_len, seq_len)

# 縮放 (避免過大的值)
scores = scores / math.sqrt(d_k)
```

**步驟 3: Softmax 轉換為概率**

```python
# 注意力權重
attention_weights = softmax(scores, dim=-1)
# (batch_size, seq_len, seq_len)
```

**步驟 4: 加權求和**

```python
# 輸出
output = attention_weights @ V
# (batch_size, seq_len, d_v)
```

#### PyTorch 實現

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class ScaledDotProductAttention(nn.Module):
    def __init__(self, temperature):
        super().__init__()
        self.temperature = temperature

    def forward(self, Q, K, V, mask=None):
        # Q, K, V: (batch, len, dim)

        # 計算注意力分數
        attn = torch.matmul(Q, K.transpose(-2, -1))
        attn = attn / self.temperature

        # 應用遮罩 (可選)
        if mask is not None:
            attn = attn.masked_fill(mask == 0, -1e9)

        # Softmax
        attn = F.softmax(attn, dim=-1)

        # 加權求和
        output = torch.matmul(attn, V)

        return output, attn
```

### 2. Multi-Head Attention (多頭注意力)

#### 核心思想

**並行運行多個注意力頭,捕捉不同的關係**

```
單頭注意力: 只有一個視角

多頭注意力: 多個視角同時工作
- Head 1: 關注語法關係
- Head 2: 關注語義關係
- Head 3: 關注位置關係
...
```

#### 架構

```
輸入 X
    ↓
分裂為多個頭
    ↓
Head 1: Attention(Q1, K1, V1)
Head 2: Attention(Q2, K2, V2)
...
Head h: Attention(Qh, Kh, Vh)
    ↓
連接所有頭的輸出
    ↓
線性變換
    ↓
輸出
```

#### PyTorch 實現

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads, dropout=0.1):
        super().__init__()
        assert d_model % n_heads == 0

        self.d_model = d_model
        self.n_heads = n_heads
        self.d_k = d_model // n_heads

        # Q, K, V 的線性變換
        self.W_Q = nn.Linear(d_model, d_model)
        self.W_K = nn.Linear(d_model, d_model)
        self.W_V = nn.Linear(d_model, d_model)

        # 輸出的線性變換
        self.W_O = nn.Linear(d_model, d_model)

        self.dropout = nn.Dropout(dropout)
        self.scale = math.sqrt(self.d_k)

    def forward(self, Q, K, V, mask=None):
        batch_size = Q.size(0)

        # 線性變換並分割為多個頭
        # (batch, seq_len, d_model) -> (batch, seq_len, n_heads, d_k)
        # -> (batch, n_heads, seq_len, d_k)
        Q = self.W_Q(Q).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        K = self.W_K(K).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)
        V = self.W_V(V).view(batch_size, -1, self.n_heads, self.d_k).transpose(1, 2)

        # 計算注意力
        scores = torch.matmul(Q, K.transpose(-2, -1)) / self.scale

        if mask is not None:
            scores = scores.masked_fill(mask == 0, -1e9)

        attn = F.softmax(scores, dim=-1)
        attn = self.dropout(attn)

        # 加權求和
        context = torch.matmul(attn, V)

        # 連接所有頭
        # (batch, n_heads, seq_len, d_k) -> (batch, seq_len, d_model)
        context = context.transpose(1, 2).contiguous().view(
            batch_size, -1, self.d_model
        )

        # 最終線性變換
        output = self.W_O(context)

        return output, attn
```

### 3. Position Encoding (位置編碼)

#### 為什麼需要?

Transformer **沒有順序概念**,需要位置編碼告訴模型詞的位置。

```
沒有位置編碼:
"我 愛 你" = "愛 你 我" = "你 我 愛"  ❌

有位置編碼:
"我 愛 你" ≠ "愛 你 我" ≠ "你 我 愛"  ✅
```

#### 正弦位置編碼

```python
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))

pos: 位置
i: 維度索引
```

**優點**:
- 可以表示任意長度序列
- 相對位置關係

```python
class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super().__init__()

        # 創建位置編碼矩陣
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)

        div_term = torch.exp(
            torch.arange(0, d_model, 2).float() *
            (-math.log(10000.0) / d_model)
        )

        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)

        pe = pe.unsqueeze(0)  # (1, max_len, d_model)
        self.register_buffer('pe', pe)

    def forward(self, x):
        # x: (batch, seq_len, d_model)
        x = x + self.pe[:, :x.size(1), :]
        return x
```

#### 可學習位置編碼

```python
class LearnedPositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super().__init__()
        self.position_embeddings = nn.Embedding(max_len, d_model)

    def forward(self, x):
        seq_len = x.size(1)
        positions = torch.arange(seq_len, device=x.device).unsqueeze(0)
        x = x + self.position_embeddings(positions)
        return x
```

### 4. Feed-Forward Network (前饋網路)

#### 結構

```
Input
  ↓
Linear (d_model → d_ff)
  ↓
ReLU / GELU
  ↓
Dropout
  ↓
Linear (d_ff → d_model)
  ↓
Output
```

**典型參數**: d_ff = 4 * d_model

```python
class PositionwiseFeedForward(nn.Module):
    def __init__(self, d_model, d_ff, dropout=0.1):
        super().__init__()
        self.w_1 = nn.Linear(d_model, d_ff)
        self.w_2 = nn.Linear(d_ff, d_model)
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        # x: (batch, seq_len, d_model)
        x = self.w_1(x)
        x = F.gelu(x)  # 或 F.relu(x)
        x = self.dropout(x)
        x = self.w_2(x)
        return x
```

### 5. Layer Normalization

#### 為什麼用 Layer Norm?

- Batch Norm: 沿 batch 維度標準化 (CNN 常用)
- Layer Norm: 沿特徵維度標準化 (Transformer 常用)

```
Layer Norm:
對每個樣本的所有特徵標準化

y = (x - mean) / sqrt(var + ε)
y = γ × y + β
```

```python
class LayerNorm(nn.Module):
    def __init__(self, features, eps=1e-6):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(features))
        self.beta = nn.Parameter(torch.zeros(features))
        self.eps = eps

    def forward(self, x):
        mean = x.mean(-1, keepdim=True)
        std = x.std(-1, keepdim=True)
        return self.gamma * (x - mean) / (std + self.eps) + self.beta
```

### 6. Residual Connection (殘差連接)

#### 作用

解決深層網路的梯度消失問題

```
x → [Sub-Layer] → Sub-Layer(x)
 ↘                    ↓
   ⊕ ←←←←←←←←←←←←←←←
   ↓
   y = x + Sub-Layer(x)
```

```python
# 在 Transformer 中的使用
x = x + self.attention(x)
x = x + self.feed_forward(x)
```

## 完整架構

### Encoder-Decoder 架構

```
Input                                 Output (shifted right)
  ↓                                         ↓
Embedding                             Embedding
  ↓                                         ↓
Positional Encoding                   Positional Encoding
  ↓                                         ↓
┌─────────────┐                       ┌─────────────────────┐
│  Encoder    │                       │    Decoder          │
│             │                       │                     │
│ × N layers  │ ─────────────────────→│  × N layers         │
│             │    (cross-attention)  │                     │
└─────────────┘                       └─────────────────────┘
                                              ↓
                                        Linear + Softmax
                                              ↓
                                          Probabilities
```

### Encoder Layer

```python
class EncoderLayer(nn.Module):
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()

        # Multi-Head Attention
        self.self_attn = MultiHeadAttention(d_model, n_heads, dropout)

        # Feed-Forward
        self.feed_forward = PositionwiseFeedForward(d_model, d_ff, dropout)

        # Layer Norm
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)

        # Dropout
        self.dropout = nn.Dropout(dropout)

    def forward(self, x, mask=None):
        # Self-Attention + Residual + Norm
        attn_output, _ = self.self_attn(x, x, x, mask)
        x = self.norm1(x + self.dropout(attn_output))

        # Feed-Forward + Residual + Norm
        ff_output = self.feed_forward(x)
        x = self.norm2(x + self.dropout(ff_output))

        return x
```

### Decoder Layer

```python
class DecoderLayer(nn.Module):
    def __init__(self, d_model, n_heads, d_ff, dropout=0.1):
        super().__init__()

        # Masked Self-Attention
        self.self_attn = MultiHeadAttention(d_model, n_heads, dropout)

        # Cross-Attention
        self.cross_attn = MultiHeadAttention(d_model, n_heads, dropout)

        # Feed-Forward
        self.feed_forward = PositionwiseFeedForward(d_model, d_ff, dropout)

        # Layer Norm
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)

        self.dropout = nn.Dropout(dropout)

    def forward(self, x, encoder_output, src_mask=None, tgt_mask=None):
        # Masked Self-Attention
        attn_output, _ = self.self_attn(x, x, x, tgt_mask)
        x = self.norm1(x + self.dropout(attn_output))

        # Cross-Attention
        attn_output, _ = self.cross_attn(x, encoder_output, encoder_output, src_mask)
        x = self.norm2(x + self.dropout(attn_output))

        # Feed-Forward
        ff_output = self.feed_forward(x)
        x = self.norm3(x + self.dropout(ff_output))

        return x
```

### 完整 Transformer

```python
class Transformer(nn.Module):
    def __init__(
        self,
        src_vocab_size,
        tgt_vocab_size,
        d_model=512,
        n_heads=8,
        num_encoder_layers=6,
        num_decoder_layers=6,
        d_ff=2048,
        dropout=0.1,
        max_len=5000
    ):
        super().__init__()

        # Embeddings
        self.src_embedding = nn.Embedding(src_vocab_size, d_model)
        self.tgt_embedding = nn.Embedding(tgt_vocab_size, d_model)

        # Positional Encoding
        self.pos_encoding = PositionalEncoding(d_model, max_len)

        # Encoder
        self.encoder_layers = nn.ModuleList([
            EncoderLayer(d_model, n_heads, d_ff, dropout)
            for _ in range(num_encoder_layers)
        ])

        # Decoder
        self.decoder_layers = nn.ModuleList([
            DecoderLayer(d_model, n_heads, d_ff, dropout)
            for _ in range(num_decoder_layers)
        ])

        # Output
        self.fc_out = nn.Linear(d_model, tgt_vocab_size)

        self.dropout = nn.Dropout(dropout)
        self.scale = math.sqrt(d_model)

    def encode(self, src, src_mask=None):
        # Embedding + Scaling + Position
        x = self.src_embedding(src) * self.scale
        x = self.pos_encoding(x)
        x = self.dropout(x)

        # Encoder layers
        for layer in self.encoder_layers:
            x = layer(x, src_mask)

        return x

    def decode(self, tgt, encoder_output, src_mask=None, tgt_mask=None):
        # Embedding + Scaling + Position
        x = self.tgt_embedding(tgt) * self.scale
        x = self.pos_encoding(x)
        x = self.dropout(x)

        # Decoder layers
        for layer in self.decoder_layers:
            x = layer(x, encoder_output, src_mask, tgt_mask)

        return x

    def forward(self, src, tgt, src_mask=None, tgt_mask=None):
        encoder_output = self.encode(src, src_mask)
        decoder_output = self.decode(tgt, encoder_output, src_mask, tgt_mask)
        output = self.fc_out(decoder_output)
        return output
```

## 變體與演進

### 1. BERT (Encoder-Only)

**結構**: 只使用 Encoder

**訓練任務**:
- Masked Language Model (MLM)
- Next Sentence Prediction (NSP)

**應用**: 文本理解、分類、NER

```
Input: [CLS] I love [MASK] [SEP]
         ↓
    BERT Encoder
         ↓
Output: [CLS] I love NLP [SEP]
```

### 2. GPT (Decoder-Only)

**結構**: 只使用 Decoder (去掉 Cross-Attention)

**訓練任務**:
- Causal Language Modeling (自回歸)

**應用**: 文本生成、對話

```
Input: I love
         ↓
   GPT Decoder
         ↓
Output: I love natural language processing
```

### 3. T5 (Encoder-Decoder)

**特點**: 所有任務統一為 text-to-text

```
Input: translate English to French: Hello
         ↓
    T5 Transformer
         ↓
Output: Bonjour
```

### 4. Vision Transformer (ViT)

**將圖像應用 Transformer**

```
Image (224×224×3)
    ↓
切分為 patches (16×16)
    ↓
Linear Embedding
    ↓
+ Position Embedding
    ↓
Transformer Encoder
    ↓
Classification Head
```

### 機器翻譯範例

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader

# 創建模型
model = Transformer(
    src_vocab_size=10000,
    tgt_vocab_size=10000,
    d_model=512,
    n_heads=8,
    num_encoder_layers=6,
    num_decoder_layers=6,
    d_ff=2048,
    dropout=0.1
)

# 訓練
optimizer = torch.optim.Adam(model.parameters(), lr=0.0001, betas=(0.9, 0.98), eps=1e-9)
criterion = nn.CrossEntropyLoss(ignore_index=PAD_IDX)

for epoch in range(num_epochs):
    model.train()
    total_loss = 0

    for src, tgt in train_loader:
        # src: (batch, src_len)
        # tgt: (batch, tgt_len)

        # 創建遮罩
        src_mask = (src != PAD_IDX).unsqueeze(1).unsqueeze(2)
        tgt_mask = create_causal_mask(tgt.size(1))

        # 前向傳播
        tgt_input = tgt[:, :-1]
        outputs = model(src, tgt_input, src_mask, tgt_mask)

        # 計算損失
        outputs = outputs.reshape(-1, outputs.shape[-1])
        tgt_output = tgt[:, 1:].reshape(-1)
        loss = criterion(outputs, tgt_output)

        # 反向傳播
        optimizer.zero_grad()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
        optimizer.step()

        total_loss += loss.item()

    print(f'Epoch {epoch+1}, Loss: {total_loss/len(train_loader):.4f}')

# 推理
def translate(model, src_sentence, src_vocab, tgt_vocab, max_len=100):
    model.eval()

    # 編碼源句子
    src_tokens = [src_vocab[token] for token in src_sentence.split()]
    src = torch.LongTensor(src_tokens).unsqueeze(0)

    # 編碼
    with torch.no_grad():
        encoder_output = model.encode(src)

    # 解碼
    tgt_tokens = [tgt_vocab['<sos>']]

    for _ in range(max_len):
        tgt = torch.LongTensor(tgt_tokens).unsqueeze(0)

        with torch.no_grad():
            output = model.decode(tgt, encoder_output)
            output = model.fc_out(output)

        next_token = output.argmax(dim=-1)[:, -1].item()
        tgt_tokens.append(next_token)

        if next_token == tgt_vocab['<eos>']:
            break

    # 轉換回文字
    tgt_sentence = [tgt_vocab.get_itos()[token] for token in tgt_tokens[1:-1]]
    return ' '.join(tgt_sentence)
```

### Causal Mask 生成

```python
def create_causal_mask(size):
    """
    創建因果遮罩 (防止看到未來的詞)
    """
    mask = torch.triu(torch.ones(size, size), diagonal=1)
    mask = mask == 0
    return mask

# 例子: size=5
# [[True,  False, False, False, False],
#  [True,  True,  False, False, False],
#  [True,  True,  True,  False, False],
#  [True,  True,  True,  True,  False],
#  [True,  True,  True,  True,  True]]
```
