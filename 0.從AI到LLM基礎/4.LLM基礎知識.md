## 什麼是 LLM

### 定義

**大型語言模型 (Large Language Model, LLM)** 是基於 Transformer 架構的超大規模神經網路,通過在海量文本數據上訓練,學習語言的模式和知識。

### 核心特徵

#### 1. 大規模參數

```
傳統模型:   百萬級參數 (10⁶)
早期 LLM:   億級參數 (10⁸-10⁹)
現代 LLM:   千億級參數 (10¹¹-10¹²)

例如:
- GPT-2:   1.5B 參數
- GPT-3:   175B 參數
- GPT-4:   估計 1.76T 參數
- LLaMA 3: 405B 參數
```

#### 2. 海量訓練數據

```
訓練數據量:
- GPT-3:    300B tokens
- PaLM:     780B tokens
- LLaMA 2:  2T tokens

數據來源:
- 網頁文本 (Common Crawl)
- 書籍
- 維基百科
- 代碼倉庫 (GitHub)
- 學術論文
```

#### 3. 湧現能力 (Emergent Abilities)

當模型規模超過某個閾值,會出現之前沒有的能力:

- 🎯 **Few-shot Learning**: 少量示例即可學習新任務
- 🧠 **Chain-of-Thought**: 推理能力
- 💻 **Code Generation**: 代碼生成
- 🌍 **Multilingual**: 多語言理解
- 📊 **Complex Reasoning**: 複雜推理

### LLM vs 傳統 NLP

| 特性 | 傳統 NLP | LLM |
|------|---------|-----|
| **模型大小** | 小 (MB) | 大 (GB-TB) |
| **訓練數據** | 任務專用 | 通用文本 |
| **任務適應** | 需要微調 | 提示即可 |
| **泛化能力** | 有限 | 強大 |
| **資源需求** | 低 | 高 |

## LLM 的演進歷史

### 階段 1: 詞嵌入時代 (2013-2017)

#### Word2Vec (2013)
```
將詞映射到向量空間
king - man + woman ≈ queen
```

#### GloVe (2014)
```
全局向量表示
```

**限制**: 靜態詞向量,無法處理一詞多義

### 階段 2: 預訓練模型時代 (2018-2019)

#### ELMo (2018)
```
雙向 LSTM
上下文相關的詞向量
```

#### BERT (2018)
```
Transformer Encoder
Masked Language Model
雙向理解
```

**突破**: 預訓練 + 微調範式

#### GPT-1 & GPT-2 (2018-2019)
```
Transformer Decoder
自回歸語言模型
文本生成
```

### 階段 3: 大規模 LLM 時代 (2020-)

#### GPT-3 (2020)
```
175B 參數
In-context Learning
Few-shot 能力
```

**革命性突破**: 無需微調,提示即可完成任務

#### 爆發性增長 (2021-2025)

```
2021: GPT-3.5, Codex
2022: ChatGPT, InstructGPT
2023: GPT-4, Claude, Gemini, LLaMA
2024: Claude 3, GPT-4 Turbo, Gemini 1.5
2025: 開源 LLM 崛起
```

## 訓練方法

### 1. 預訓練 (Pre-training)

#### 目標

在大規模無標註文本上學習語言的通用表示。

#### 訓練任務

**因果語言建模 (Causal LM)**:
```
給定: "我愛"
預測: "自然語言處理"

損失函數:
L = -Σ log P(token_i | token_<i)
```

**實現**:
```python
# 簡化的預訓練過程
for batch in dataloader:
    # batch: "我愛自然語言處理"

    # 輸入: "我愛自然語言"
    # 目標: "愛自然語言處理"
    inputs = batch[:, :-1]
    targets = batch[:, 1:]

    # 前向傳播
    logits = model(inputs)

    # 計算損失
    loss = cross_entropy(logits, targets)

    # 反向傳播
    loss.backward()
    optimizer.step()
```

#### 計算需求

```
訓練 GPT-3 (175B):
- GPU: 10,000+ A100
- 時間: 數週
- 成本: 數百萬美元

訓練 LLaMA 2 (70B):
- GPU: 2,000 A100
- 時間: 2-3 週
```

### 2. 監督微調 (Supervised Fine-Tuning, SFT)

#### 目標

在高質量的指令-回應數據對上微調模型。

#### 數據格式

```json
{
  "instruction": "解釋什麼是機器學習",
  "output": "機器學習是一種讓計算機..."
}
```

#### 訓練

```python
# 使用 Hugging Face Trainer
from transformers import Trainer, TrainingArguments

training_args = TrainingArguments(
    output_dir="./sft_model",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    learning_rate=2e-5,
    logging_steps=100,
)

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
)

trainer.train()
```

### 3. 強化學習 (RLHF)

**Reinforcement Learning from Human Feedback**

#### 流程

```
1. 收集人類偏好數據
   模型生成多個回應 → 人類排序

2. 訓練獎勵模型
   學習人類偏好 → Reward Model

3. PPO 訓練
   使用 RL 優化策略 → 更好的模型
```

#### 獎勵建模

```python
class RewardModel(nn.Module):
    def __init__(self, base_model):
        super().__init__()
        self.base_model = base_model
        self.value_head = nn.Linear(hidden_size, 1)

    def forward(self, input_ids):
        outputs = self.base_model(input_ids)
        rewards = self.value_head(outputs.last_hidden_state)
        return rewards
```

#### PPO 訓練

```python
# 簡化的 PPO 過程
for epoch in range(num_epochs):
    # 1. 生成回應
    responses = model.generate(prompts)

    # 2. 計算獎勵
    rewards = reward_model(responses)

    # 3. 計算優勢
    advantages = rewards - baseline

    # 4. PPO 更新
    loss = ppo_loss(old_logprobs, new_logprobs, advantages)
    loss.backward()
    optimizer.step()
```

### 4. 新興訓練方法

#### DPO (Direct Preference Optimization)

**直接優化偏好,無需獎勵模型**

```python
# DPO 損失
loss = -log(σ(β * (log π(y_w|x) - log π(y_l|x))))

# y_w: 偏好的回應
# y_l: 不偏好的回應
# β: 溫度參數
```

#### RLAIF (RL from AI Feedback)

**使用 AI 而非人類提供反饋**

```
優點:
- 成本低
- 可擴展
- 一致性好
```

## 關鍵技術

### 1. Tokenization (分詞)

#### BPE (Byte-Pair Encoding)

```
原始文本: "unhappiness"
         ↓
子詞單元: ["un", "happiness"]
         ↓
Token IDs: [142, 5683]
```

```python
# 使用 Tokenizer
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("gpt2")

text = "Hello, world!"
tokens = tokenizer.tokenize(text)
ids = tokenizer.encode(text)

print(f"Tokens: {tokens}")
print(f"IDs: {ids}")

# 解碼
decoded = tokenizer.decode(ids)
print(f"Decoded: {decoded}")
```

### 3. 模型壓縮

#### 量化 (Quantization)

```
FP32 → FP16 / INT8 / INT4

例如:
- 70B 模型 FP32: 280GB
- 70B 模型 INT4:  35GB

工具:
- GPTQ
- AWQ
- GGUF
```

```python
# 使用量化模型
from transformers import AutoModelForCausalLM, BitsAndBytesConfig

quantization_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_compute_dtype=torch.float16
)

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-2-70b",
    quantization_config=quantization_config
)
```

#### LoRA (Low-Rank Adaptation)

```
高效微調方法
只訓練少量參數

W' = W + ΔW
ΔW = A × B

A: (d × r), r << d
B: (r × d)
```

```python
# 使用 LoRA
from peft import LoraConfig, get_peft_model

lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    target_modules=["q_proj", "v_proj"],
    lora_dropout=0.05,
)

model = get_peft_model(base_model, lora_config)
```

### 主要限制

#### 1. 幻覺 (Hallucination)

```
問題: 生成看似合理但錯誤的內容

緩解方法:
- RAG (檢索增強)
- 事實檢查
- 提供來源
```

#### 2. 知識截止日期

```
問題: 只知道訓練截止前的信息

解決:
- 定期更新
- 外部知識庫
- 實時搜索
```

#### 3. 推理能力有限

```
問題: 複雜邏輯推理困難

改進:
- Chain-of-Thought
- ReAct 框架
- 工具使用
```

#### 4. 偏見問題

```
問題: 訓練數據的偏見

應對:
- 數據過濾
- 對齊訓練
- 持續監控
```

#### 5. 資源消耗

```
問題: 訓練/推理成本高

優化:
- 模型壓縮
- 蒸餾
- 邊緣部署
```
