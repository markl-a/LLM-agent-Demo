## 什麼是人工智慧

### 定義

**人工智慧 (Artificial Intelligence, AI)** 是指由人類創造的系統所展現出的智慧能力,包括:

- 🧠 **學習能力**: 從經驗中獲取知識
- 🔍 **推理能力**: 使用邏輯進行推斷
- 🗣️ **理解能力**: 理解自然語言和圖像
- 🎯 **決策能力**: 在複雜環境中做出決策
- 🔄 **適應能力**: 適應新的情況和問題

### AI vs 傳統程式設計

| 特性 | 傳統程式設計 | AI 系統 |
|------|------------|---------|
| **邏輯** | 明確規則 | 從數據學習 |
| **靈活性** | 低 | 高 |
| **處理複雜性** | 有限 | 強大 |
| **可解釋性** | 高 | 低到中 |
| **數據需求** | 低 | 高 |

### 核心概念

```
傳統程式設計:
輸入 + 規則 → 輸出

機器學習:
輸入 + 輸出 → 規則 (模型)

AI 應用:
輸入 + 學習到的模型 → 預測/決策
```

## AI 發展歷史

- 專家系統發展

#### 2000s - 機器學習時代
- **2006**: 深度學習概念提出

## AI 的分類

### 按能力分類

#### 1. 弱人工智慧 (Narrow AI / ANI)
- **定義**: 專注於特定任務的 AI
- **特點**:
  - 在特定領域表現優異
  - 無法遷移到其他領域
  - 目前絕大多數 AI 都屬於此類
- **例子**:
  - 語音助手 (Siri, Alexa)
  - 圖像識別系統
  - 推薦系統
  - 下棋程式

#### 2. 強人工智慧 (General AI / AGI)
- **定義**: 具有人類級別智能的 AI
- **特點**:
  - 可以理解、學習任何智力任務
  - 具有遷移學習能力
  - 目前尚未實現
- **目標**:
  - 像人類一樣思考
  - 解決各種問題
  - 自主學習和適應

#### 3. 超人工智慧 (Super AI / ASI)
- **定義**: 超越人類智能的 AI
- **特點**:
  - 在所有領域都超越人類
  - 理論階段
  - 引發倫理和安全討論

### 按技術分類

#### 1. 規則基礎系統 (Rule-Based)

#### 2. 機器學習系統 (Machine Learning)
- 監督式學習
- 非監督式學習
- 強化學習

#### 3. 深度學習系統 (Deep Learning)
- 神經網路
- 卷積神經網路 (CNN)
- 循環神經網路 (RNN)
- Transformer

#### 4. 符號 AI (Symbolic AI)
- 知識圖譜
- 邏輯推理
- 專家系統

## AI 的核心技術

### 1. 機器學習 (Machine Learning)

**核心概念**: 讓機器從數據中自動學習模式

#### 主要類型

##### 監督式學習 (Supervised Learning)
```
訓練數據: (輸入, 正確答案) 配對
目標: 學習輸入到輸出的映射關係

應用例子:
- 圖像分類 (貓 vs 狗)
- 垃圾郵件偵測
- 房價預測
```

##### 非監督式學習 (Unsupervised Learning)
```
訓練數據: 只有輸入,沒有標籤
目標: 發現數據中的隱藏模式

應用例子:
- 客戶分群
- 異常偵測
- 降維
```

##### 強化學習 (Reinforcement Learning)
```
訓練方式: 通過獎勵和懲罰學習
目標: 學習在環境中採取最優行動

應用例子:
- 遊戲 AI (AlphaGo)
- 機器人控制
- 自動駕駛
```

### 2. 深度學習 (Deep Learning)

**核心概念**: 使用多層神經網路學習數據的層次化表示

#### 基本架構

```
輸入層 → 隱藏層1 → 隱藏層2 → ... → 輸出層
   ↓         ↓          ↓              ↓
  像素     邊緣特徵   形狀特徵      物體類別
```

#### 關鍵技術

1. **反向傳播 (Backpropagation)**
   - 計算梯度
   - 更新權重
   - 最小化損失函數

2. **激活函數 (Activation Functions)**
   - ReLU: `f(x) = max(0, x)`
   - Sigmoid: `f(x) = 1 / (1 + e^-x)`
   - Tanh: `f(x) = (e^x - e^-x) / (e^x + e^-x)`

3. **正則化 (Regularization)**
   - Dropout
   - L1/L2 正則化
   - Batch Normalization

### 3. 自然語言處理 (NLP)

**核心概念**: 讓機器理解和生成人類語言

#### 關鍵技術

1. **詞嵌入 (Word Embeddings)**
   - Word2Vec
   - GloVe
   - FastText

2. **序列模型**
   - RNN (循環神經網路)
   - LSTM (長短期記憶網路)
   - GRU (門控循環單元)

3. **注意力機制 (Attention)**
   - Self-Attention
   - Multi-Head Attention
   - Cross-Attention

4. **Transformer**
   - BERT
   - GPT
   - T5

### 4. 電腦視覺 (Computer Vision)

**核心概念**: 讓機器理解視覺信息

#### 關鍵技術

1. **卷積神經網路 (CNN)**
   - 卷積層 (Convolution)
   - 池化層 (Pooling)
   - 全連接層 (Fully Connected)

2. **物體偵測**
   - R-CNN 系列
   - YOLO
   - SSD

3. **圖像分割**
   - FCN
   - U-Net
   - Mask R-CNN

4. **生成模型**
   - GAN
   - VAE
   - Diffusion Models

## 📐 AI 必備數學基礎

### 為什麼需要數學?

```
AI/ML 的本質是數學:
- 線性代數: 數據表示和轉換
- 微積分: 優化和梯度下降
- 概率統計: 不確定性建模
```

### 1. 線性代數基礎

#### 向量和矩陣

```python
import numpy as np

# 向量表示
v = np.array([1, 2, 3])  # 3維向量

# 矩陣表示
A = np.array([
    [1, 2],
    [3, 4],
    [5, 6]
])  # 3x2 矩陣

# 矩陣乘法 (神經網路的核心運算)
x = np.array([1, 2])
y = A @ x  # 結果: [5, 11, 17]
```

**為什麼重要**:
- 數據以向量/矩陣形式存儲
- 神經網路是矩陣運算
- 降維技術(PCA)基於線性代數

#### 關鍵概念

```
向量空間、基向量、正交性
特徵值、特徵向量
矩陣分解 (SVD, 特徵分解)
```

### 2. 微積分基礎

#### 導數和梯度

```python
# 函數: f(x) = x²
def f(x):
    return x ** 2

# 導數: f'(x) = 2x
def f_derivative(x):
    return 2 * x

# 梯度下降示例
x = 10  # 初始點
learning_rate = 0.1

for i in range(10):
    gradient = f_derivative(x)
    x = x - learning_rate * gradient
    print(f"步驟 {i+1}: x = {x:.4f}, f(x) = {f(x):.4f}")

# 收斂到 x ≈ 0 (最小值)
```

**為什麼重要**:
- 反向傳播基於鏈式法則
- 梯度下降用於優化
- 理解模型如何學習

#### 關鍵概念

```
偏導數、梯度
鏈式法則
泰勒展開
凸優化
```

### 3. 概率統計基礎

#### 概率分佈

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

# 正態分佈 (高斯分佈)
mu, sigma = 0, 1
x = np.linspace(-4, 4, 100)
y = stats.norm.pdf(x, mu, sigma)

plt.plot(x, y)
plt.title('正態分佈 N(0,1)')
plt.xlabel('x')
plt.ylabel('概率密度')
plt.show()
```

**為什麼重要**:
- 數據分佈建模
- 貝葉斯推理
- 不確定性量化

#### 關鍵概念

```
期望值、方差
條件概率、貝葉斯定理
最大似然估計
信息熵
```

### 實踐練習

**練習 1: 數學基礎**
```python
# 實現簡單的梯度下降
def gradient_descent(f, df, x0, learning_rate=0.1, iterations=100):
    """
    f: 目標函數
    df: 導數函數
    x0: 初始點
    """
    x = x0
    history = [x]

    for i in range(iterations):
        gradient = df(x)
        x = x - learning_rate * gradient
        history.append(x)

    return x, history

# 測試: 最小化 f(x) = (x-3)²
f = lambda x: (x - 3) ** 2
df = lambda x: 2 * (x - 3)

result, history = gradient_descent(f, df, x0=0)
print(f"最小值點: x = {result:.4f}")
```
