## 什麼是提示工程

### 定義

**提示工程 (Prompt Engineering)** 是設計和優化輸入提示的過程,以引導 LLM 產生期望的輸出。

### 為什麼重要?

```
同樣的問題,不同的提示:

❌ 差的提示: "翻譯這個"
   → 模糊,不知道翻譯什麼、翻譯成什麼語言

✅ 好的提示: "將以下英文翻譯成繁體中文:Hello, world!"
   → 明確,包含所有必要信息
```

### 提示的組成

```
完整提示 = 角色 + 任務 + 上下文 + 格式 + 示例

例如:
┌────────────────────────────────────┐
│ 角色: 你是一位專業的Python開發者  │
│ 任務: 編寫一個函數                │
│ 上下文: 用於計算斐波那契數列      │
│ 格式: 包含docstring和類型提示     │
│ 示例: def fib(n: int) -> int:     │
└────────────────────────────────────┘
```

## 基本原則

### 1. 清晰明確

#### ❌ 模糊的提示

```
"寫一些關於AI的東西"
```

#### ✅ 清晰的提示

```
請寫一篇500字的文章,介紹深度學習在圖像識別中的應用,
包括:
1. 深度學習的基本概念
2. 卷積神經網路的工作原理
3. 在圖像識別中的具體應用案例
4. 未來發展趨勢

目標讀者是對AI有基本了解的大學生。
```

### 2. 提供上下文

#### ❌ 缺少上下文

```
"這個bug怎麼修?"
```

#### ✅ 豐富的上下文

```
我在使用Python編寫一個網頁爬蟲時遇到錯誤:

錯誤信息:
ConnectionError: Max retries exceeded

相關代碼:
```python
import requests
url = "https://example.com"
response = requests.get(url)
```

環境:
- Python 3.9
- requests 2.28.0
- 網絡連接正常

請幫我分析原因並提供解決方案。
```

### 3. 分步驟指示

#### ❌ 一次性要求

```
"分析這個數據集並給我結論"
```

#### ✅ 分步驟

```
請對以下數據集進行分析:

步驟1: 查看數據集的基本統計信息
步驟2: 識別缺失值和異常值
步驟3: 分析變量之間的相關性
步驟4: 繪製關鍵變量的分布圖
步驟5: 總結主要發現和建議

請按步驟執行並說明每一步的發現。
```

### 4. 指定輸出格式

#### ❌ 未指定格式

```
"給我一些產品特點"
```

#### ✅ 指定格式

```
請以JSON格式列出產品的5個主要特點:

{
  "features": [
    {
      "name": "特點名稱",
      "description": "詳細描述",
      "benefit": "用戶獲益"
    },
    ...
  ]
}
```

## 核心技巧

### 1. Zero-Shot Prompting

**定義**: 不提供示例,直接描述任務

```
提示:
將以下句子翻譯成法語:"Good morning, how are you?"

輸出:
Bonjour, comment allez-vous?
```

**適用**: 簡單、明確的任務

### 2. Few-Shot Prompting

**定義**: 提供少量示例來引導模型

```
提示:
將句子分類為正面或負面情感:

例子1:
輸入: 這部電影太棒了!
輸出: 正面

例子2:
輸入: 服務很差,不推薦。
輸出: 負面

例子3:
輸入: 這家餐廳的食物一般般。
輸出: 中性

現在分類:
輸入: 產品質量超出預期,非常滿意!
輸出:
```

**適用**: 需要特定格式或風格的任務

### 3. Chain-of-Thought (CoT)

**定義**: 引導模型展示推理過程

#### 標準提示

```
問題: 一個籃子裡有15個蘋果,媽媽拿走了5個,
      然後弟弟又放進去3個,現在有多少個蘋果?

答案: 13個
```

#### CoT 提示

```
問題: 一個籃子裡有15個蘋果,媽媽拿走了5個,
      然後弟弟又放進去3個,現在有多少個蘋果?

讓我們一步一步思考:

步驟1: 最初有15個蘋果
步驟2: 媽媽拿走5個,剩下 15 - 5 = 10個
步驟3: 弟弟放進去3個,總共 10 + 3 = 13個

答案: 13個蘋果
```

**觸發詞**: "讓我們一步一步思考"

### 4. Self-Consistency

**定義**: 多次採樣,選擇最一致的答案

```python
# 多次提問同一個問題
answers = []
for i in range(5):
    response = llm.generate(prompt)
    answers.append(response)

# 選擇最常出現的答案
final_answer = most_common(answers)
```

### 5. Tree of Thoughts (ToT)

**定義**: 探索多個推理路徑

```
問題: 如何提高網站轉化率?

思路1: 優化用戶體驗
  → 改善頁面加載速度
  → 簡化註冊流程
  → 優化移動端體驗

思路2: 改進內容策略
  → 提供更有價值的內容
  → 優化SEO
  → 增加社交證明

思路3: 完善營銷策略
  → A/B測試
  → 個性化推薦
  → 再營銷活動

評估每條思路並選擇最佳方案...
```

## 進階技術

### 1. 角色扮演 (Role Playing)

```
你是一位有20年經驗的資深軟體架構師,
擅長分布式系統設計和性能優化。

現在有一個電商系統需要支持每秒10萬次請求,
請設計一個可擴展的架構方案。

要求:
- 考慮高可用性
- 成本優化
- 維護便利性
```

### 2. 格式化輸出

#### JSON 格式

```
請以JSON格式提供分析結果:

{
  "summary": "總結",
  "key_findings": ["發現1", "發現2"],
  "recommendations": [
    {
      "action": "行動項",
      "priority": "高/中/低",
      "impact": "影響描述"
    }
  ]
}
```

#### Markdown 格式

```
請以Markdown格式撰寫技術文檔:

# 標題
## 功能描述
- 功能1
- 功能2

## 使用方法
```python
# 代碼示例
```

## 注意事項
> 重要提示
```

### 3. 約束條件

```
請推薦3個Python網頁爬蟲庫,要求:

必須滿足:
✓ 活躍維護
✓ 文檔完整
✓ 支持異步

優先考慮:
⭐ 簡單易用
⭐ 社區活躍
⭐ 性能優異

輸出格式:
庫名 | 優點 | 缺點 | 適用場景
```

### 4. 多輪對話

```
用戶: 我想學習機器學習

助手: 很好!為了給你更好的建議,請問:
1. 你的編程基礎如何?(Python經驗)
2. 數學基礎如何?(線性代數、微積分)
3. 學習目標是什麼?(工作需要/興趣愛好)

用戶: Python熟練,數學基礎一般,想應用到工作

助手: 了解了!基於你的情況,我建議以下學習路徑:
[提供定制化建議...]
```

### 5. 思維鏈與工具結合

```
問題: 現在北京時間幾點?東京呢?

思考過程:
1. 我需要獲取當前時間 → 使用get_current_time("Beijing")
2. 東京時間比北京快1小時 → 使用get_current_time("Tokyo")
   或 計算: Beijing_time + 1小時

執行:
[調用工具...]

結果:
- 北京時間: 14:30
- 東京時間: 15:30
```

## 實戰案例

### 案例 1: 代碼生成

```
任務: 編寫Python函數,實現二分搜索

提示:
請編寫一個Python函數實現二分搜索算法。

要求:
1. 函數名: binary_search
2. 參數: arr (已排序列表), target (目標值)
3. 返回: 目標值的索引,如果不存在返回-1
4. 包含完整的docstring和類型提示
5. 包含錯誤處理
6. 時間複雜度: O(log n)

示例:
```python
arr = [1, 3, 5, 7, 9]
result = binary_search(arr, 5)
# 返回: 2
```

請提供完整實現和測試用例。
```

### 案例 2: 數據分析

```
我有一份銷售數據CSV文件,包含以下欄位:
- date: 日期
- product: 產品名稱
- category: 產品類別
- quantity: 銷售數量
- revenue: 營收

請用Python進行分析:

1. 讀取數據並處理缺失值
2. 計算:
   - 總營收
   - 每個類別的營收佔比
   - 銷售趨勢(按月)
3. 可視化:
   - 類別營收餅圖
   - 月度銷售趨勢線圖
4. 給出業務洞察和建議

請提供完整代碼和分析報告。
```

### 案例 3: 文本處理

```
任務: 從客戶評論中提取關鍵信息

輸入文本:
"這家餐廳的環境很好,裝潢很有特色。
服務員態度也不錯,很熱情。但是菜品份量有點少,
價格偏貴,性價比一般。下次可能不會再來了。"

請提取:
1. 情感傾向: 正面/中性/負面
2. 提及方面:
   - 環境: [評價]
   - 服務: [評價]
   - 菜品: [評價]
   - 價格: [評價]
3. 整體評分: 1-5分
4. 再次消費意願: 高/中/低
5. 關鍵詞: [列表]

以JSON格式輸出。
```

### 案例 4: 創意寫作

```
寫一篇科技部落格文章:

主題: "2025年AI發展趨勢"

要求:
1. 字數: 800-1000字
2. 結構:
   - 引言 (吸引讀者)
   - 3-5個主要趨勢 (每個200字左右)
   - 結論 (展望未來)
3. 風格: 專業但易懂
4. 包含: 數據支持、案例舉例
5. SEO: 自然融入關鍵詞"AI"、"人工智慧"、"機器學習"

目標讀者: 對AI感興趣的科技從業者
```

## 最佳實踐

### 1. 迭代優化

```
初始提示 → 測試 → 分析結果 → 改進 → 再測試

例子:

V1: "總結這篇文章"
   → 輸出太簡單

V2: "用3-5個要點總結這篇文章的主要內容"
   → 缺少關鍵信息

V3: "請仔細閱讀文章,然後:
     1. 用一句話概括主題
     2. 列出3-5個核心觀點
     3. 總結作者的結論
     保持客觀,不添加個人意見"
   → ✅ 達到預期
```

### 2. 使用分隔符

```
請分析以下客戶反饋:

---
反饋內容開始
我對產品很滿意,但物流太慢了!
反饋內容結束
---

請從以下角度分析:
1. 產品滿意度
2. 服務問題
3. 改進建議
```

### 3. 設置溫度參數

```python
# 創意任務 (高溫度)
response = llm.generate(
    prompt="寫一個創意廣告標語",
    temperature=0.9  # 更有創意
)

# 事實性任務 (低溫度)
response = llm.generate(
    prompt="總結產品規格",
    temperature=0.1  # 更精確
)
```

### 4. 錯誤處理提示

```
請回答以下問題。如果你不確定或不知道答案,
請誠實地說"我不確定",不要編造信息。

問題: 2025年諾貝爾物理獎得主是誰?

如果信息不在你的知識庫中,請回答:
"抱歉,我的知識截止於[日期],無法提供2025年的信息。"
```

### 5. 示例庫建立

```
建立常用提示模板庫:

templates/
├── code_generation.txt
├── data_analysis.txt
├── content_writing.txt
├── translation.txt
└── summarization.txt

使用時:
template = load_template("code_generation.txt")
prompt = template.format(
    function_name="binary_search",
    description="實現二分搜索"
)
```

## 提示工程工具

### 1. LangChain PromptTemplate

```python
from langchain.prompts import PromptTemplate

template = """
你是一位{role}。

任務: {task}

要求:
{requirements}

請提供詳細的回答。
"""

prompt = PromptTemplate(
    input_variables=["role", "task", "requirements"],
    template=template
)

formatted_prompt = prompt.format(
    role="Python專家",
    task="優化這段代碼",
    requirements="1. 提高性能\n2. 增加可讀性"
)
```

### 2. Few-Shot Prompt Template

```python
from langchain.prompts import FewShotPromptTemplate

examples = [
    {"input": "happy", "output": "sad"},
    {"input": "tall", "output": "short"},
]

example_prompt = PromptTemplate(
    input_variables=["input", "output"],
    template="Input: {input}\nOutput: {output}"
)

few_shot_prompt = FewShotPromptTemplate(
    examples=examples,
    example_prompt=example_prompt,
    prefix="Give the antonym of every input",
    suffix="Input: {input}\nOutput:",
    input_variables=["input"]
)

print(few_shot_prompt.format(input="big"))
```

## 常見錯誤

### ❌ 過於複雜

```
請運用後現代主義解構理論框架,
結合量子力學的不確定性原理,
從社會學、心理學和哲學三個維度,
深入剖析當代消費主義文化現象...
```

### ✅ 簡潔清晰

```
請從社會、心理、經濟三個角度,
分析現代消費文化的特徵和影響。
約500字。
```

### ❌ 模糊指令

```
幫我寫點東西關於機器學習
```

### ✅ 明確指令

```
請寫一篇800字的入門文章,
介紹機器學習的基本概念,
面向沒有技術背景的讀者。
```

## 🎯 總結

### 核心原則

1. **清晰**: 明確任務和期望
2. **具體**: 提供細節和約束
3. **結構化**: 分步驟、有格式
4. **上下文**: 豐富的背景信息
5. **迭代**: 持續測試和優化

### 技巧層次

```
基礎: Zero-Shot, Few-Shot
進階: Chain-of-Thought, 角色扮演
高級: Tree of Thoughts, ReAct
```
