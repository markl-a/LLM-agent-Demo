================================================================================
                                  核心特性
================================================================================

✨ 自動知識圖譜構建
  • 使用 LLM 自動提取實體和關係
  • 無需人工標註
  • 支持大規模文檔處理

🔍 雙模式搜索
  • Local Search：精確的實體關係查詢
  • Global Search：基於社區的宏觀理解
  • Hybrid Search：智能策略選擇

🌐 社區檢測
  • Leiden 算法進行層次化檢測
  • 自動生成社區摘要
  • 支持多層次分析

📊 可視化支持
  • 靜態圖（Matplotlib）
  • 互動式圖表（Plotly）
  • 社區結構可視化
  • 統計報表生成

🏢 企業級功能
  • 性能優化（緩存、並行）
  • 監控和日誌
  • 安全驗證
  • 高可用部署

================================================================================
                                快速開始
================================================================================

1. 安裝依賴：
   pip install -r requirements.txt

2. 配置 API 密鑰（創建 .env 文件）：
   GRAPHRAG_API_KEY=your_openai_api_key_here

3. 運行示例：
   python 01_快速開始.py

4. 查看文檔：
   cat README.md
   cat QUICKSTART.md

                              與傳統 RAG 對比
================================================================================

GraphRAG 優勢：
  ✓ 支持全局理解和主題總結
  ✓ 提供更好的可解釋性
  ✓ 支持複雜的多跳推理
  ✓ 能發現隱藏的知識關聯

適用場景：
  • 需要理解整體趨勢和主題

  • 需要高度的結果可解釋性
