# 實際應用案例

本目錄包含多個 LLM Agent 的實際應用案例，涵蓋不同場景和技術棧。

## 📁 案例列表

### 1. [客服機器人](./客服機器人/)
使用 LangChain + LangGraph 構建的智能客服系統

**功能特點**:
- 多輪對話管理
- 意圖識別和路由
- 知識庫檢索
- 工單創建和追蹤

**技術棧**: LangChain, LangGraph, FastAPI, Redis

---

### 2. [文檔問答系統](./文檔問答系統/)
基於 RAG 的企業文檔問答系統

**功能特點**:
- 多種文檔格式支持（PDF, Word, Excel）
- 智能分塊和索引
- 語義搜索
- 引用來源追蹤

**技術棧**: LlamaIndex, OpenAI, Chroma, Streamlit

---

### 3. [智能搜索引擎](./智能搜索引擎/)
結合傳統搜索和 AI 的混合搜索系統

**功能特點**:
- 關鍵詞 + 語義搜索
- 搜索結果重排序
- 自動摘要生成
- 相關問題推薦

**技術棧**: LangChain, Elasticsearch, FAISS

---

### 4. [程式碼助手](./程式碼助手/)
AI 驅動的程式碼理解和生成助手

**功能特點**:
- 代碼分析和解釋
- 代碼生成和補全
- Bug 檢測和修復建議
- 代碼審查輔助

**技術棧**: LangChain, AutoGen, GitHub Copilot API

---

## 🚀 快速開始

每個案例目錄都包含：

1. `README.md` - 詳細說明和使用指南
2. `requirements.txt` - 依賴列表
3. `main.py` 或 `app.py` - 主程序
4. `config.yaml` - 配置文件
5. `examples/` - 使用範例

### 基本使用流程

```bash
# 1. 進入案例目錄
cd 客服機器人/

# 2. 安裝依賴
pip install -r requirements.txt

# 3. 配置環境變數
cp .env.example .env
# 編輯 .env 添加 API Keys

# 4. 運行程序
python main.py
```

## 🔧 通用配置

所有案例都支持以下環境變數：

```bash
# OpenAI
OPENAI_API_KEY=your_key

# Google Gemini（可選）
GOOGLE_API_KEY=your_key

# 向量數據庫（根據案例需要）
PINECONE_API_KEY=your_key
PINECONE_ENVIRONMENT=your_env

# 其他服務
SERPER_API_KEY=your_key  # 搜索 API
```
