## Agent 類型層次結構

```
ConversableAgent (基類)
├── AssistantAgent (助理 Agent)
│   ├── 使用 LLM 生成回復
│   ├── 支持工具調用
│   └── 可配置 system_message
├── UserProxyAgent (用戶代理 Agent)
│   ├── 可執行程式碼
│   ├── 可接受人工輸入
│   └── 管理代碼執行環境
└── GroupChatManager (群組管理 Agent)
    ├── 管理多 Agent 對話
    ├── 控制發言順序
    └── 協調對話流程
```

### Agent 類型對比

| 特性 | ConversableAgent | AssistantAgent | UserProxyAgent |
|------|-----------------|----------------|----------------|
| LLM 調用 | ✅ (可選) | ✅ (必須) | ❌ (默認) |
| 代碼執行 | ✅ (可選) | ❌ (默認) | ✅ (推薦) |
| 人工輸入 | ✅ (可選) | ❌ (默認) | ✅ (可選) |
| 工具調用 | ✅ (可選) | ✅ (支持) | ✅ (執行) |
| 使用場景 | 自定義 Agent | AI 助理 | 執行/人機交互 |

## ConversableAgent 核心概念

### 基本結構

```python
from autogen import ConversableAgent

agent = ConversableAgent(
    name="agent_name",              # Agent 名稱（必須）
    system_message="...",           # 系統提示詞
    llm_config={...},               # LLM 配置
    human_input_mode="NEVER",       # 人工輸入模式
    max_consecutive_auto_reply=5,   # 最大自動回復次數
    is_termination_msg=lambda x: False,  # 終止條件
    code_execution_config=False,    # 代碼執行配置
    function_map={},                # 函數映射
    default_auto_reply="",          # 默認自動回復
)
```

### 關鍵參數說明

#### 1. `name` (必須)
Agent 的唯一標識符，在對話中用於區分不同的 Agent。

```python
# ✅ 好的命名
assistant = ConversableAgent(name="數據分析師", ...)
reviewer = ConversableAgent(name="代碼審查員", ...)

# ❌ 避免的命名
agent1 = ConversableAgent(name="agent", ...)  # 太通用
agent2 = ConversableAgent(name="a1", ...)     # 不清晰
```

#### 2. `system_message`
定義 Agent 的角色、能力和行為規範。

```python
system_message = """你是一個專業的 Python 開發專家。

你的職責：
1. 編寫高質量、可維護的 Python 代碼
2. 遵循 PEP 8 編碼規範
3. 提供詳細的代碼註釋
4. 考慮邊界情況和錯誤處理

回復格式：
- 首先說明你的理解
- 然後提供代碼實現
- 最後解釋關鍵部分

限制：
- 不要使用已棄用的 API
- 優先使用標準庫
- 注重性能和安全性
"""

agent = ConversableAgent(
    name="Python專家",
    system_message=system_message,
    llm_config=llm_config
)
```

#### 3. `human_input_mode`
控制何時請求人工輸入。

```python
# 從不請求人工輸入（完全自動）
agent1 = ConversableAgent(
    name="auto_agent",
    human_input_mode="NEVER"
)

# 僅在終止時請求
agent2 = ConversableAgent(
    name="terminate_agent",
    human_input_mode="TERMINATE"
)

# 每次都請求人工輸入
agent3 = ConversableAgent(
    name="human_agent",
    human_input_mode="ALWAYS"
)
```

| 模式 | 說明 | 使用場景 |
|------|------|---------|
| `NEVER` | 從不請求人工輸入 | 完全自動化任務 |
| `TERMINATE` | 僅在檢測到終止消息時請求 | 需要最終確認的任務 |
| `ALWAYS` | 每次回復前都請求 | 需要人工監督的任務 |

#### 4. `max_consecutive_auto_reply`
限制連續自動回復的次數，防止無限循環。

```python
# 最多自動回復 5 次
agent = ConversableAgent(
    name="agent",
    max_consecutive_auto_reply=5
)

# 無限制（不推薦）
agent = ConversableAgent(
    name="agent",
    max_consecutive_auto_reply=None  # 危險！
)
```

**最佳實踐**：
- 簡單任務：3-5 次
- 複雜任務：10-15 次
- 始終設置上限

#### 5. `is_termination_msg`
自定義終止條件。

```python
# 檢查是否包含 "TERMINATE"
agent1 = ConversableAgent(
    name="agent1",
    is_termination_msg=lambda x: x.get("content", "").rstrip().endswith("TERMINATE")
)

# 檢查特定關鍵詞
agent2 = ConversableAgent(
    name="agent2",
    is_termination_msg=lambda x: any(
        word in x.get("content", "").lower()
        for word in ["完成", "結束", "done", "finished"]
    )
)

# 複雜條件
def custom_termination(msg):
    content = msg.get("content", "")
    # 檢查是否包含終止標記
    if "TERMINATE" in content:
        return True
    # 檢查是否達到目標
    if "目標已達成" in content:
        return True
    # 檢查是否出錯
    if msg.get("role") == "error":
        return True
    return False

agent3 = ConversableAgent(
    name="agent3",
    is_termination_msg=custom_termination
)
```

## 消息處理機制

### 消息流程

```
發送消息
    ↓
[_process_received_message]
    ↓
[generate_reply]
    ↓
├── [generate_oai_reply]      # LLM 回復
├── [generate_code_execution_reply]  # 代碼執行回復
├── [generate_function_call_reply]   # 函數調用回復
└── [check_termination_and_human_reply]  # 檢查終止和人工輸入
    ↓
[send]
    ↓
接收回復
```

### 自定義回復生成

```python
from autogen import ConversableAgent
from typing import Dict, Optional, Union, List

class CustomAgent(ConversableAgent):
    """自定義 Agent 示例"""

    def generate_reply(
        self,
        messages: Optional[List[Dict]] = None,
        sender: Optional["Agent"] = None,
        **kwargs,
    ) -> Union[str, Dict, None]:
        """
        自定義回復生成邏輯

        Args:
            messages: 消息列表
            sender: 發送者 Agent
            **kwargs: 其他參數

        Returns:
            回復內容
        """
        # 1. 獲取最後一條消息
        last_message = messages[-1] if messages else {}
        content = last_message.get("content", "")

        # 2. 自定義處理邏輯
        if "緊急" in content:
            return "我會優先處理緊急任務！"

        if "幫助" in content:
            return self._generate_help_message()

        # 3. 調用父類方法（使用 LLM）
        return super().generate_reply(messages, sender, **kwargs)

    def _generate_help_message(self) -> str:
        """生成幫助信息"""
        return """
        我可以幫助你：
        1. 回答問題
        2. 生成代碼
        3. 分析數據
        4. 提供建議
        """
```

### 註冊自定義回復方法

```python
# 註冊回復方法
def custom_reply_func(
    recipient: ConversableAgent,
    messages: Optional[List[Dict]] = None,
    sender: Optional[ConversableAgent] = None,
    config: Optional[Any] = None,
) -> Tuple[bool, Optional[Union[str, Dict]]]:
    """
    自定義回復函數

    Returns:
        (是否處理, 回復內容)
    """
    last_message = messages[-1] if messages else {}
    content = last_message.get("content", "")

    # 檢查是否匹配特定模式
    if "天氣" in content:
        return True, "今天天氣很好！"

    # 不處理，交給下一個回復方法
    return False, None

# 註冊到 Agent
agent = ConversableAgent(name="agent", llm_config=llm_config)
agent.register_reply(
    trigger=lambda sender: True,  # 觸發條件
    reply_func=custom_reply_func,
    position=0  # 優先級（數字越小優先級越高）
)
```

### 3. 回調和鉤子

```python
class CallbackAgent(ConversableAgent):
    """支持回調的 Agent"""

    def __init__(self, name, **kwargs):
        super().__init__(name=name, **kwargs)
        self.callbacks = {
            "before_reply": [],
            "after_reply": [],
            "on_error": []
        }

    def register_callback(self, event: str, callback: callable):
        """註冊回調函數"""
        if event in self.callbacks:
            self.callbacks[event].append(callback)

    def generate_reply(self, messages=None, sender=None, **kwargs):
        """帶回調的回復生成"""
        try:
            # 執行前置回調
            for cb in self.callbacks["before_reply"]:
                cb(messages, sender)

            # 生成回復
            reply = super().generate_reply(messages, sender, **kwargs)

            # 執行後置回調
            for cb in self.callbacks["after_reply"]:
                cb(reply, sender)

            return reply
        except Exception as e:
            # 執行錯誤回調
            for cb in self.callbacks["on_error"]:
                cb(e, messages, sender)
            raise

# 使用示例
def log_before_reply(messages, sender):
    print(f"準備回復來自 {sender.name} 的消息")

def log_after_reply(reply, sender):
    print(f"已回復 {sender.name}")

agent = CallbackAgent(name="agent", llm_config=llm_config)
agent.register_callback("before_reply", log_before_reply)
agent.register_callback("after_reply", log_after_reply)
```

## 最佳實踐

### ✅ 推薦做法

1. **清晰的命名**
   ```python
   # ✅ 好
   data_analyst = ConversableAgent(name="數據分析師", ...)

   # ❌ 差
   agent1 = ConversableAgent(name="a1", ...)
   ```

2. **詳細的 system_message**
   ```python
   # ✅ 好 - 明確角色、能力、限制
   system_message = """
   你是專業的Python工程師。

   能力：
   - 編寫高質量代碼
   - 遵循PEP 8規範

   限制：
   - 不使用已棄用API
   - 優先使用標準庫
   """
   ```

3. **合理的終止條件**
   ```python
   # ✅ 好
   is_termination_msg=lambda x: x.get("content", "").rstrip().endswith("TERMINATE")
   max_consecutive_auto_reply=10
   ```

4. **錯誤處理**
   ```python
   # ✅ 好
   try:
       reply = agent.generate_reply(messages, sender)
   except Exception as e:
       logger.error(f"生成回復失敗: {e}")
       reply = "抱歉，處理請求時出錯。"
   ```

### ❌ 避免的做法

1. ❌ 無限自動回復
2. ❌ 不設置終止條件
3. ❌ 過於模糊的 system_message
4. ❌ 忽略錯誤處理
5. ❌ 不限制 token 使用
