# PromptLayer - LLM 請求監控平台

## 簡介

PromptLayer 是一個專為大型語言模型（LLM）應用設計的可觀測性和監控平台。它提供了完整的請求追蹤、提示管理、版本控制和團隊協作功能，幫助開發者和團隊更好地管理、調試和優化 LLM 應用。

PromptLayer 支持所有主流 LLM 提供商（OpenAI、Anthropic、Cohere 等），通過簡單的 SDK 整合即可記錄所有 LLM 請求，並提供強大的 Web 界面進行分析和管理。它特別適合需要追蹤 LLM 使用情況、優化提示效果、控制成本和進行團隊協作的應用場景。

## 核心特點

### 1. 請求追蹤和記錄
- **自動記錄**: 透明記錄所有 LLM 請求和響應
- **詳細元數據**: 記錄時間戳、延遲、token 使用等
- **請求歷史**: 完整的請求歷史記錄
- **搜索過濾**: 強大的搜索和過濾功能

### 2. 提示模板管理
- **模板庫**: 集中管理所有提示模板
- **版本控制**: 完整的模板版本歷史
- **變量支持**: 動態變量替換
- **模板共享**: 團隊內共享模板

### 3. 版本管理和測試
- **A/B 測試**: 對比不同提示版本
- **回歸測試**: 確保更新不影響質量
- **版本回滾**: 快速回滾到之前版本
- **性能對比**: 分析不同版本的效果

### 4. 評分和評估
- **人工評分**: 手動評分請求質量
- **自動評估**: 基於規則的自動評分
- **團隊評分**: 多人協作評估
- **評分統計**: 評分數據分析

### 5. 成本分析
- **實時追蹤**: 實時 token 使用追蹤
- **成本預測**: 基於歷史數據的成本預測
- **預算告警**: 超出預算時告警
- **詳細報表**: 按項目、用戶等維度統計

### 6. 團隊協作
- **多用戶支持**: 完整的用戶權限管理
- **項目隔離**: 多項目獨立管理
- **共享儀表板**: 團隊共享分析視圖
- **評論討論**: 針對請求的評論功能

## 核心概念

### Request（請求）
每次 LLM 調用都會被記錄為一個請求：

```python
import promptlayer

promptlayer.api_key = "your-api-key"

# OpenAI 包裝器
openai = promptlayer.openai

# 自動記錄請求
response = openai.ChatCompletion.create(
    model="gpt-4",
    messages=[{"role": "user", "content": "Hello"}]
)
```

### Template（模板）
集中管理的提示模板：

```python
# 使用模板
response = promptlayer.run(
    prompt_name="greeting_template",
    prompt_version=1,
    input_variables={"name": "張三"}
)
```

### Tag（標籤）
為請求添加標籤便於組織：

```python
# 添加標籤
promptlayer.track.openai(
    request_id,
    tags=["production", "customer-service"]
)
```

### Score（評分）
對請求質量進行評分：

```python
# 評分
promptlayer.track.score(
    request_id=request_id,
    score=100,  # 0-100
    metadata={"evaluated_by": "human"}
)
```
