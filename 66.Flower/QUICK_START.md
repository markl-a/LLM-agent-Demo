# 66.Flower 快速开始指南

## 🎯 框架简介

Flower 是一个友好的联邦学习框架，专注于隐私保护的 AI 训练。本教程包含 10 个完整示例，从基础到生产部署全覆盖。

## 💡 核心概念速查

### 联邦学习流程
```
初始化 → 选择客户端 → 分发模型 → 本地训练 → 上传更新 → 聚合 → 重复
```

### 关键组件
- **Client**: 持有数据，执行本地训练
- **Server**: 协调训练，聚合更新
- **Strategy**: 定义聚合算法（FedAvg, FedProx 等）
- **Config**: 控制训练超参数

### 隐私保护机制
- **差分隐私**: 添加噪声保护数据
- **安全聚合**: 加密聚合防止推断
- **本地训练**: 数据不离开设备
