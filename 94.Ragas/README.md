# Ragas - RAG 評估框架

## 簡介

Ragas（Retrieval Augmented Generation Assessment）是專為評估 RAG（檢索增強生成）系統設計的評估框架。它提供了一套完整的指標來評估 RAG 應用的性能，包括忠實度、相關性、上下文精度等多個維度。

## 核心特性

### 1. **多維度評估**
- 忠實度（Faithfulness）：答案是否忠實於上下文
- 答案相關性（Answer Relevance）：答案與問題的相關性
- 上下文精度（Context Precision）：檢索上下文的精確度
- 上下文召回（Context Recall）：檢索上下文的完整性

### 2. **無需標籤數據**
- 使用 LLM 進行自動評估
- 無需人工標註的測試集
- 快速評估 RAG 系統性能

### 3. **易於整合**
- 與 LangChain 無縫整合
- 支持多種向量數據庫
- 可整合到 CI/CD 流程

### 4. **全面的報告**
- 詳細的評估報告
- 視覺化分析
- 基準測試對比

## 主要組件

### 評估指標

1. **Faithfulness（忠實度）**
   - 衡量答案是否基於提供的上下文
   - 檢測幻覺問題

2. **Answer Relevance（答案相關性）**
   - 評估答案與問題的相關程度
   - 避免離題回答

3. **Context Precision（上下文精度）**
   - 檢索的上下文是否精確
   - 減少無關信息

4. **Context Recall（上下文召回）**
   - 是否檢索到所有相關信息
   - 避免遺漏重要內容

5. **Answer Similarity（答案相似度）**
   - 與參考答案的語義相似度
   - 評估答案質量

## 評估流程

```python
from ragas import evaluate
from ragas.metrics import faithfulness, answer_relevancy

# 準備評估數據
dataset = {
    'question': ['問題1', '問題2'],
    'answer': ['答案1', '答案2'],
    'contexts': [['上下文1'], ['上下文2']]
}

# 執行評估
result = evaluate(
    dataset,
    metrics=[faithfulness, answer_relevancy]
)

# 查看結果
print(result)
```

## 常見問題

### Q: Ragas 需要 GPU 嗎？
A: 不需要，但使用 GPU 可以加速評估過程。

### Q: 如何處理中文 RAG 系統？
A: Ragas 支持多語言，確保使用支持中文的 LLM 模型。

### Q: 評估成本如何？
A: 成本取決於使用的 LLM 和評估數據量，建議先小規模測試。

### Q: 可以離線使用嗎？
A: 可以，使用本地部署的 LLM 模型。
