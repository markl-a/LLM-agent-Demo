# Burr - 應用狀態機框架

## 簡介

Burr 是由 DAGWorks 開發的 Python 狀態機框架，專為構建可追蹤、可測試、可維護的 AI 應用而設計。它將應用邏輯建模為狀態機，提供清晰的狀態轉換、完整的追蹤能力和時間旅行調試功能。

Burr 特別適合構建需要複雜狀態管理的 AI Agent、聊天機器人、工作流程系統等應用。它強調透明性、可觀測性和可維護性，是構建生產級 AI 應用的優秀選擇。

## 快速開始

```python
from burr.core import action, State, ApplicationBuilder

# 定義動作
@action(reads=["counter"], writes=["counter"])
def increment(state: State) -> State:
    return state.update(counter=state["counter"] + 1)

@action(reads=["counter"], writes=["counter"])
def decrement(state: State) -> State:
    return state.update(counter=state["counter"] - 1)

# 構建應用
app = (
    ApplicationBuilder()
    .with_state(counter=0)
    .with_actions(increment, decrement)
    .with_transitions(
        ("increment", "decrement"),
        ("decrement", "increment")
    )
    .with_entrypoint("increment")
    .build()
)

# 執行
action_result, state, _ = app.step()
print(f"Counter: {state['counter']}")  # Counter: 1
```

## 核心概念

### 1. State（狀態）
應用的數據容器，不可變設計：
- 使用 `.get()` 讀取值
- 使用 `.update()` 更新值
- 自動追蹤變更歷史

### 2. Action（動作）
狀態轉換的基本單位：
- 使用 `@action` 裝飾器定義
- 明確聲明讀取和寫入的狀態
- 返回新的狀態對象

### 3. Transition（轉換）
定義動作之間的流轉：
- 靜態轉換：固定的下一個動作
- 動態轉換：基於條件的分支
- 支持循環和終止條件

### 4. Application（應用）
狀態機的容器：
- 管理狀態和動作
- 執行狀態轉換
- 提供追蹤和持久化

## 常見問題

### Q: Burr 與 LangGraph 有什麼區別？
A: Burr 是框架無關的狀態機框架，更注重狀態管理和可測試性。LangGraph 是 LangChain 的一部分，更適合圖形化工作流。

### Q: 如何啟動 Burr UI？
A: 安裝 `burr[start]` 後，在代碼中使用 `.with_tracker(tracker="local")` 啟用追蹤，然後運行 `burr` 命令啟動 UI。

### Q: Burr 支持異步嗎？
A: 是的，Burr 完全支持異步動作和異步應用執行。

### Q: 如何實現條件分支？
A: 使用 `default` 參數和條件函數來定義動態轉換。參見 04_條件分支.py。

### Q: 狀態可以持久化到資料庫嗎？
A: 可以，Burr 支持自定義持久化後端，可以輕鬆實現資料庫持久化。
