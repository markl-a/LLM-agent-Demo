## 評估指標體系

### 檢索質量指標

#### 1. Precision @ K (P@K)

```
P@K = (檢索到的相關文檔數) / K

示例：
查詢："2023 Q4 營收數據"
Top 5 檢索結果：
1. ✅ 2023 Q4 財報表格
2. ✅ 2023 Q4 營收趨勢圖
3. ❌ 2023 Q3 營收數據
4. ✅ 2023 年度營收對比
5. ❌ 2022 Q4 營收數據

P@5 = 3/5 = 0.6
```

**特點**：
- 衡量檢索結果的準確性
- 不考慮召回率
- 適合關注用戶體驗（前幾個結果是否有用）

#### 2. Recall @ K (R@K)

```
R@K = (檢索到的相關文檔數) / (總相關文檔數)

示例：
數據庫中總共有 8 個與查詢相關的文檔
Top 5 檢索到了其中 3 個

R@5 = 3/8 = 0.375
```

**特點**：
- 衡量檢索的完整性
- 不考慮精確率
- 適合需要全面覆蓋的場景

#### 3. Mean Average Precision (MAP)

```
對於單個查詢：
AP = Σ(P@k × rel(k)) / (相關文檔總數)

其中：
- P@k: 前 k 個結果的 Precision
- rel(k): 第 k 個結果是否相關（0 或 1）

對於多個查詢：
MAP = Σ(AP) / (查詢總數)

示例：
查詢："2023 Q4 營收"
結果序列：✅ ❌ ✅ ❌ ✅

AP = (1/1 + 2/3 + 3/5) / 3
   = (1.0 + 0.667 + 0.6) / 3
   = 0.756
```

**特點**：
- 綜合考慮精確率和相關文檔的位置
- 獎勵將相關文檔排在前面的檢索系統
- 業界廣泛使用的指標

#### 4. Normalized Discounted Cumulative Gain (NDCG)

```
DCG@K = Σ(rel_i / log2(i+1))

NDCG@K = DCG@K / IDCG@K

其中：
- rel_i: 第 i 個文檔的相關性評分（0-3）
- IDCG: 理想情況下的 DCG（最優排序）

示例：
查詢結果相關性：[3, 2, 0, 1, 3]

DCG@5 = 3/log2(2) + 2/log2(3) + 0/log2(4) + 1/log2(5) + 3/log2(6)
      = 3.0 + 1.26 + 0 + 0.43 + 1.16
      = 5.85

理想排序：[3, 3, 2, 1, 0]
IDCG@5 = 3/log2(2) + 3/log2(3) + 2/log2(4) + 1/log2(5) + 0
       = 3.0 + 1.89 + 1.0 + 0.43 + 0
       = 6.32

NDCG@5 = 5.85 / 6.32 = 0.926
```

**特點**：
- 考慮相關性的程度（不是二元的相關/不相關）
- 考慮排序位置（前面的文檔權重更高）
- 適合多級相關性評估

```
定義：答案在多大程度上利用了檢索到的上下文

評估方法：
def evaluate_context_utilization(answer, retrieved_docs):
```

### 系統性能指標

#### 1. 延遲（Latency）

```
總延遲 = 文檔解析 + 摘要生成 + 檢索 + 答案生成

典型延遲分佈：
┌────────────────┬──────────┬──────────┬──────────┐
│ 階段           │ 最小值   │ 中位數   │ P95      │
├────────────────┼──────────┼──────────┼──────────┤
│ 文檔解析（離線）│ 10s      │ 30s      │ 60s      │
│ 摘要生成（離線）│ 5s       │ 15s      │ 30s      │
│ 檢索（線上）    │ 50ms     │ 100ms    │ 200ms    │
│ 答案生成（線上）│ 2s       │ 5s       │ 10s      │
└────────────────┴──────────┴──────────┴──────────┘
```

**測量方法**：

```python
import time
from collections import defaultdict

class LatencyMonitor:
    def __init__(self):
        self.latencies = defaultdict(list)

    def measure(self, stage_name):
        """上下文管理器，測量某個階段的延遲"""
        class Timer:
            def __enter__(timer_self):
                timer_self.start = time.time()
                return timer_self

            def __exit__(timer_self, *args):
                latency = time.time() - timer_self.start
                self.latencies[stage_name].append(latency)

        return Timer()

    def report(self):
        """生成延遲報告"""
        import numpy as np

        report = {}
        for stage, latencies in self.latencies.items():
            report[stage] = {
                "min": np.min(latencies),
                "median": np.median(latencies),
                "p95": np.percentile(latencies, 95),
                "p99": np.percentile(latencies, 99),
                "mean": np.mean(latencies)
            }

        return report

# 使用示例
monitor = LatencyMonitor()

with monitor.measure("retrieval"):
    docs = retriever.invoke(query)

with monitor.measure("generation"):
    answer = llm.invoke(query, docs)

print(monitor.report())
```

#### 2. 吞吐量（Throughput）

```
吞吐量 = 處理的查詢數 / 時間

目標：
- 小規模應用：10-50 QPS (Queries Per Second)
- 中規模應用：50-200 QPS
- 大規模應用：200+ QPS
```

**測量方法**：

```python
import asyncio
from concurrent.futures import ThreadPoolExecutor
import time

async def benchmark_throughput(queries, rag_system, duration=60):
    """
    基準測試吞吐量

    參數：
    - queries: 測試查詢列表
    - rag_system: RAG 系統實例
    - duration: 測試持續時間（秒）
    """
    processed = 0
    errors = 0
    start_time = time.time()

    async def process_query(query):
        try:
            await rag_system.aquery(query)
            return True
        except Exception:
            return False

    # 並發執行查詢
    tasks = []
    while time.time() - start_time < duration:
        for query in queries:
            task = asyncio.create_task(process_query(query))
            tasks.append(task)

        results = await asyncio.gather(*tasks)
        processed += len(results)
        errors += sum(1 for r in results if not r)
        tasks = []

    elapsed = time.time() - start_time
    qps = processed / elapsed

    return {
        "qps": qps,
        "total_queries": processed,
        "errors": errors,
        "error_rate": errors / processed
    }
```

#### 3. 成本效率

```
成本效率 = 處理的查詢數 / 總成本

成本分解：
1. API 成本
   - 嵌入：$0.0001 / 1K tokens
   - GPT-4o 視覺：$0.01 / image
   - GPT-4o 文本：$0.03 / 1K tokens（輸出）

2. 基礎設施成本
   - 向量庫：$70/month（Pinecone starter）
   - 服務器：$100/month（AWS）

3. 存儲成本
   - S3：$0.023/GB/month
```

**成本計算器**：

```python
class CostCalculator:
    # API 定價（美元）
    PRICING = {
        "embedding": 0.0001 / 1000,  # per token
        "gpt4o_input": 0.005 / 1000,
        "gpt4o_output": 0.015 / 1000,
        "gpt4o_image": 0.00765,  # per image (1024x1024)
        "gpt4_turbo_input": 0.01 / 1000,
        "gpt4_turbo_output": 0.03 / 1000,
    }

    def calculate_query_cost(self, query_stats):
        """
        計算單個查詢的成本

        query_stats = {
            "embedding_tokens": 100,
            "retrieved_images": 2,
            "input_tokens": 2000,
            "output_tokens": 500
        }
        """
        cost = 0

        # 嵌入成本
        cost += query_stats["embedding_tokens"] * self.PRICING["embedding"]

        # 圖像處理成本
        cost += query_stats["retrieved_images"] * self.PRICING["gpt4o_image"]

        # LLM 成本
        cost += query_stats["input_tokens"] * self.PRICING["gpt4o_input"]
        cost += query_stats["output_tokens"] * self.PRICING["gpt4o_output"]

        return cost

    def estimate_monthly_cost(self, daily_queries, avg_query_stats):
        """估算月度成本"""
        cost_per_query = self.calculate_query_cost(avg_query_stats)
        daily_cost = cost_per_query * daily_queries
        monthly_cost = daily_cost * 30

        return {
            "per_query": cost_per_query,
            "daily": daily_cost,
            "monthly": monthly_cost
        }

# 使用示例
calculator = CostCalculator()

avg_stats = {
    "embedding_tokens": 50,
    "retrieved_images": 1.5,
    "input_tokens": 1500,
    "output_tokens": 300
}

costs = calculator.estimate_monthly_cost(
    daily_queries=1000,
    avg_query_stats=avg_stats
)

print(f"每個查詢成本：${costs['per_query']:.4f}")
print(f"每日成本：${costs['daily']:.2f}")
print(f"每月成本：${costs['monthly']:.2f}")
```

### 評估框架

```python
from dataclasses import dataclass
from typing import List, Dict
import numpy as np

@dataclass
class EvaluationResult:
    """評估結果數據類"""
    query_id: str
    query: str
    retrieved_docs: List[str]
    answer: str
    metrics: Dict[str, float]

class RAGEvaluator:
    """RAG 系統完整評估框架"""

    def __init__(self, rag_system, test_dataset):
        self.rag_system = rag_system
        self.test_dataset = test_dataset

    def evaluate(self):
        """運行完整評估"""
        results = []

        for query_item in self.test_dataset["queries"]:
            result = self._evaluate_single_query(query_item)
            results.append(result)

        return self._aggregate_results(results)

    def _evaluate_single_query(self, query_item):
        """評估單個查詢"""
        query = query_item["query"]

        # 執行檢索和生成
        retrieved_docs = self.rag_system.retrieve(query)
        answer = self.rag_system.generate(query, retrieved_docs)

        # 計算各項指標
        metrics = {}

        # 1. 檢索指標
        metrics["precision@5"] = self._calc_precision(
            retrieved_docs, query_item["relevant_docs"], k=5
        )
        metrics["recall@5"] = self._calc_recall(
            retrieved_docs, query_item["relevant_docs"], k=5
        )
        metrics["ndcg@5"] = self._calc_ndcg(
            retrieved_docs, query_item["relevance_scores"], k=5
        )

        # 2. 生成指標
        metrics["faithfulness"] = self._calc_faithfulness(
            answer, retrieved_docs
        )
        metrics["relevance"] = self._calc_relevance(
            query, answer
        )
        metrics["completeness"] = self._calc_completeness(
            answer, query_item["expected_answer_points"]
        )

        return EvaluationResult(
            query_id=query_item["id"],
            query=query,
            retrieved_docs=[d.id for d in retrieved_docs],
            answer=answer,
            metrics=metrics
        )

    def _calc_precision(self, retrieved, relevant, k):
        """計算 Precision@K"""
        retrieved_k = [d.id for d in retrieved[:k]]
        relevant_set = set(relevant)
        relevant_retrieved = set(retrieved_k) & relevant_set
        return len(relevant_retrieved) / k if k > 0 else 0

    def _calc_recall(self, retrieved, relevant, k):
        """計算 Recall@K"""
        retrieved_k = [d.id for d in retrieved[:k]]
        relevant_set = set(relevant)
        relevant_retrieved = set(retrieved_k) & relevant_set
        return len(relevant_retrieved) / len(relevant_set) if relevant else 0

    def _calc_ndcg(self, retrieved, relevance_scores, k):
        """計算 NDCG@K"""
        dcg = 0
        for i, doc in enumerate(retrieved[:k]):
            rel = relevance_scores.get(doc.id, 0)
            dcg += rel / np.log2(i + 2)

        # 計算 IDCG
        ideal_scores = sorted(relevance_scores.values(), reverse=True)[:k]
        idcg = sum(rel / np.log2(i + 2) for i, rel in enumerate(ideal_scores))

        return dcg / idcg if idcg > 0 else 0

    def _calc_faithfulness(self, answer, retrieved_docs):
        """使用 LLM 評估忠實度"""
        docs_text = "\n\n".join([d.page_content for d in retrieved_docs])

        prompt = f"""
        評估答案是否基於提供的文檔，評分 0-1：

        文檔：
        {docs_text}

        答案：
        {answer}

        只返回一個 0-1 之間的數字：
        """

        score = self.evaluator_llm.invoke(prompt)
        return float(score.strip())

    def _calc_relevance(self, query, answer):
        """使用 LLM 評估相關性"""
        prompt = f"""
        評估答案對問題的相關性，評分 0-1：

        問題：{query}
        答案：{answer}

        只返回一個 0-1 之間的數字：
        """

        score = self.evaluator_llm.invoke(prompt)
        return float(score.strip())

    def _calc_completeness(self, answer, expected_points):
        """計算答案的完整性"""
        covered = 0
        for point in expected_points:
            # 簡單的字符串匹配（可以改進為語義匹配）
            if any(keyword in answer for keyword in point.split()):
                covered += 1

        return covered / len(expected_points) if expected_points else 0

    def _aggregate_results(self, results):
        """聚合所有結果"""
        metrics_summary = {}

        # 計算每個指標的平均值
        all_metrics = [r.metrics for r in results]
        metric_names = all_metrics[0].keys()

        for metric in metric_names:
            values = [m[metric] for m in all_metrics]
            metrics_summary[metric] = {
                "mean": np.mean(values),
                "std": np.std(values),
                "min": np.min(values),
                "max": np.max(values)
            }

        return {
            "summary": metrics_summary,
            "details": results
        }
```

```python
def optimize_chunk_size(documents, queries, chunk_sizes=[500, 1000, 2000, 4000]):

    results = {}

    for chunk_size in chunk_sizes:

        }
```

```python
from langchain_community.retrievers import BM25Retriever

def create_hybrid_retriever(documents, alpha=0.5):
    """
    創建混合檢索器

    alpha: 向量檢索權重
    1-alpha: BM25 檢索權重
    """
    # 向量檢索器
    vectorstore = Chroma.from_documents(documents, embeddings)
    vector_retriever = vectorstore.as_retriever(k=10)

    # BM25 檢索器
    bm25_retriever = BM25Retriever.from_documents(documents)
    bm25_retriever.k = 10

    # 混合檢索器
    ensemble_retriever = EnsembleRetriever(
        retrievers=[vector_retriever, bm25_retriever],
        weights=[alpha, 1-alpha]
    )

    return ensemble_retriever

# 調優 alpha 參數
def tune_alpha(documents, queries, alphas=[0.3, 0.5, 0.7]):
    best_alpha = None
    best_score = 0

    for alpha in alphas:
        retriever = create_hybrid_retriever(documents, alpha)

        scores = []
        for query in queries:
            docs = retriever.invoke(query)
            score = evaluate_retrieval(docs, query.relevant_docs)
            scores.append(score)

        mean_score = np.mean(scores)

        if mean_score > best_score:
            best_score = mean_score
            best_alpha = alpha

    return best_alpha, best_score
```

```python
class SmartImageProcessor:
    """智能圖像處理器：只在需要時處理圖像"""

    def __init__(self):
        self.image_classifier = self._load_classifier()

    def should_process_image(self, image, query):
        """判斷是否需要處理圖像"""

        # 1. 查詢意圖分析
        if not self._query_needs_visual(query):
            return False

        # 2. 圖像類型分類
        image_type = self.image_classifier.predict(image)
        if image_type in ["decorative", "logo"]:
            return False

        # 3. 圖像質量檢查
        if not self._is_high_quality(image):
            return False

        return True

    def _query_needs_visual(self, query):
        """判斷查詢是否需要視覺資訊"""
        visual_keywords = [
            "圖表", "趨勢", "顏色", "分佈", "對比",
            "圖", "展示", "顯示", "視覺"
        ]
        return any(kw in query for kw in visual_keywords)

    def _is_high_quality(self, image):
        """檢查圖像質量"""
        # 檢查解析度、清晰度等
        height, width = image.shape[:2]

        if width < 200 or height < 200:
            return False  # 太小

        if self._calc_sharpness(image) < 0.3:
            return False  # 太模糊

        return True
```

```python
class AdaptiveModelSelector:
    """自適應模型選擇器"""

    def select_model(self, query, complexity_threshold=0.5):
        """根據查詢複雜度選擇模型"""

        complexity = self._estimate_complexity(query)

        if complexity < complexity_threshold:
            return "gpt-3.5-turbo"  # 便宜的模型
        else:
            return "gpt-4o"  # 強大的模型

    def _estimate_complexity(self, query):
        """估計查詢複雜度"""

        features = {
            "length": min(len(query.split()) / 50, 1.0),
            "technical_terms": self._count_technical_terms(query) / 10,
            "multi_hop": 1.0 if self._requires_reasoning(query) else 0.0,
            "comparison": 1.0 if "比較" in query or "對比" in query else 0.0
        }

        # 加權平均
        weights = {
            "length": 0.2,
            "technical_terms": 0.3,
            "multi_hop": 0.3,
            "comparison": 0.2
        }

        complexity = sum(features[k] * weights[k] for k in features)

        return complexity
```
