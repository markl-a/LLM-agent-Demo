# Mem0 - AI 記憶層

## 簡介

Mem0 是專為 AI 應用構建的智能記憶層,提供持久化、可搜索和上下文感知的記憶管理。它能夠讓 AI 應用記住用戶互動、偏好和歷史上下文,從而提供更加個性化和智能的體驗。Mem0 支持多種 AI 模型,可以輕鬆整合到現有的 AI 應用中。

Mem0 的核心理念是讓 AI 擁有長期記憶能力,就像人類一樣能夠記住過去的經驗並在未來的互動中運用這些知識。它特別適合構建聊天機器人、個人助手、推薦系統等需要記憶能力的 AI 應用。

## 核心特點

### 1. 智能記憶管理
- **自動記憶提取**: 從對話中自動識別和提取重要信息
- **語義理解**: 基於 LLM 的語義記憶存儲
- **上下文感知**: 理解記憶的上下文和關聯
- **去重機制**: 自動合併相似或重複的記憶
- **重要性評分**: 自動評估記憶的重要程度

### 2. 多維度記憶
- **用戶記憶**: 記住每個用戶的偏好和歷史
- **會話記憶**: 追蹤對話上下文
- **實體記憶**: 記住人、地點、事物等實體信息
- **關係記憶**: 記錄實體間的關係
- **時間記憶**: 保留時間序列信息

### 3. 高級搜索
- **語義搜索**: 基於語義相似度的智能搜索
- **過濾查詢**: 按用戶、時間、類型等過濾
- **相關性排序**: 智能排序最相關的記憶
- **聚合查詢**: 跨多個記憶源的聚合搜索
- **模糊匹配**: 支持模糊和近似匹配

### 4. 記憶生命週期
- **自動過期**: 設置記憶的生命週期
- **記憶更新**: 智能更新過時的信息
- **記憶合併**: 合併相關記憶減少冗余
- **記憶歸檔**: 歸檔不常用的記憶
- **記憶刪除**: 遵守隱私的記憶刪除

### 5. 多模態支持
- **文本記憶**: 對話、文檔等文本信息
- **圖像記憶**: 圖片描述和視覺信息
- **音頻記憶**: 語音和音頻轉錄
- **結構化數據**: JSON、表格等結構化信息
- **文件記憶**: PDF、文檔等文件內容

### 6. 企業級特性
- **多租戶**: 支持多用戶和組織隔離
- **訪問控制**: 細粒度的權限管理
- **數據加密**: 敏感數據的加密存儲
- **審計日誌**: 完整的操作記錄
- **高可用**: 分佈式部署支持
- **API限流**: 防止濫用的限流機制

## 快速開始

### 基礎使用

```python
from mem0 import Memory

# 初始化記憶
memory = Memory()

# 添加記憶
memory.add(
    "用戶喜歡喝咖啡,特別是美式咖啡",
    user_id="user_123"
)

# 搜索記憶
results = memory.search(
    "用戶的飲品偏好",
    user_id="user_123"
)

# 獲取所有記憶
all_memories = memory.get_all(user_id="user_123")
```

### 配置記憶系統

```python
from mem0 import Memory

config = {
    "vector_store": {
        "provider": "qdrant",
        "config": {
            "host": "localhost",
            "port": 6333
        }
    },
    "llm": {
        "provider": "openai",
        "config": {
            "model": "gpt-4",
            "api_key": "your-api-key"
        }
    },
    "embedder": {
        "provider": "openai",
        "config": {
            "model": "text-embedding-3-small"
        }
    }
}

memory = Memory.from_config(config)
```

## 核心概念

### 記憶對象

每個記憶包含以下屬性:

```python
{
    "id": "unique_memory_id",
    "memory": "記憶內容",
    "user_id": "user_123",
    "created_at": "2024-01-01T00:00:00",
    "updated_at": "2024-01-01T00:00:00",
    "metadata": {
        "importance": 8,
        "category": "preference",
        "source": "conversation"
    }
}
```

### 用戶隔離

```python
# 用戶 A 的記憶
memory.add("喜歡紅色", user_id="user_a")

# 用戶 B 的記憶
memory.add("喜歡藍色", user_id="user_b")

# 搜索時自動隔離
results_a = memory.search("喜歡的顏色", user_id="user_a")  # 返回 "紅色"
results_b = memory.search("喜歡的顏色", user_id="user_b")  # 返回 "藍色"
```

### 記憶更新

```python
# 添加記憶
memory.add("用戶住在台北", user_id="user_123")

# 更新記憶(自動識別並更新)
memory.add("用戶住在台中", user_id="user_123")  # 會更新而非新增

# 手動更新
memory.update(
    memory_id="memory_id",
    data="新的記憶內容"
)
```

### 記憶刪除

```python
# 刪除特定記憶
memory.delete(memory_id="memory_id")

# 刪除用戶所有記憶
memory.delete_all(user_id="user_123")

# 批量刪除
memory.delete_many(memory_ids=["id1", "id2", "id3"])
```

## 最佳實踐

### 1. 記憶粒度
- **細粒度**: 將複雜信息拆分為多個記憶
- **明確性**: 記憶內容要清晰明確
- **原子性**: 每個記憶應該是獨立的
- **可搜索**: 確保記憶內容可被有效搜索

### 2. 記憶組織
- 使用適當的 metadata 標記記憶
- 為記憶設置合理的重要性分數
- 定期清理過時的記憶
- 建立記憶的層次結構

### 3. 性能優化
- 使用向量數據庫加速搜索
- 合理設置記憶過期時間
- 批量操作提升效率
- 使用緩存減少 API 調用

### 4. 隱私安全
- 加密敏感記憶內容
- 實施訪問控制
- 定期審計記憶訪問
- 遵守數據保護法規

### 5. 擴展性
- 選擇可擴展的向量數據庫
- 實施分片策略
- 使用異步操作
- 監控系統性能
