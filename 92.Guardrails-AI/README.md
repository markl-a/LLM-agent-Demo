# Guardrails AI - LLM 輸出驗證框架

## 簡介

Guardrails AI 是一個開源的 Python 框架，專門用於為大型語言模型（LLM）添加結構化驗證、安全護欄和可靠性保障。它確保 LLM 的輸出符合預期的格式、質量和安全標準。

## 核心特性

- **結構化輸出驗證**：確保 LLM 輸出符合指定的 schema
- **數據質量檢查**：驗證輸出的準確性、完整性和一致性
- **安全護欄**：檢測並過濾敏感信息（PII）、有毒內容等
- **自動重試機制**：當驗證失敗時自動重試並修正
- **流式驗證**：支持流式輸出的實時驗證
- **自定義驗證器**：靈活創建自定義驗證規則
- **多 LLM 支持**：兼容 OpenAI、Anthropic、Cohere 等

## 安裝

```bash
pip install guardrails-ai openai
```

## 主要概念

### Guard（護欄）
Guard 是 Guardrails 的核心概念，定義了 LLM 輸出必須滿足的驗證規則。

### Validators（驗證器）
驗證器是具體的驗證規則，如：
- `DetectPII`：檢測個人身份信息
- `ToxicLanguage`：檢測有毒語言
- `ValidJSON`：驗證 JSON 格式
- `ValidRange`：驗證數值範圍
- 自定義驗證器

### Rail Spec
RAIL（Reliable AI Markup Language）是用於定義驗證規則的 DSL。

## 使用場景

1. **結構化數據提取**：確保 LLM 生成符合 schema 的 JSON/XML
2. **內容安全**：過濾敏感信息和不當內容
3. **業務規則驗證**：確保輸出符合業務邏輯
4. **質量保證**：驗證輸出的完整性和準確性
5. **合規性檢查**：確保符合法規要求（如 GDPR）

## 架構優勢

1. **防禦性編程**：在 LLM 輸出進入系統前進行驗證
2. **可組合性**：多個驗證器可以組合使用
3. **透明度**：清晰的驗證日誌和錯誤報告
4. **性能優化**：支持並行驗證和緩存
5. **可擴展性**：易於添加自定義驗證邏輯

## 與其他框架的集成

- **LangChain**：可作為 LangChain 的輸出解析器
- **LlamaIndex**：驗證檢索增強生成（RAG）的輸出
- **AutoGen**：為多智能體系統添加護欄
- **任何 LLM API**：通用的驗證層

## 最佳實踐

1. **漸進式驗證**：從簡單驗證開始，逐步添加複雜規則
2. **合理的重試次數**：避免過度重試造成成本浪費
3. **明確的錯誤處理**：為驗證失敗提供清晰的回退策略
4. **監控和日誌**：記錄驗證結果用於優化
5. **性能考量**：平衡驗證嚴格度和響應速度

## 注意事項

- 需要設置環境變量 `OPENAI_API_KEY`
- 某些驗證器可能需要額外的依賴包
- 驗證會增加延遲，需要在安全性和性能間權衡
- 建議在開發環境充分測試後再部署到生產
