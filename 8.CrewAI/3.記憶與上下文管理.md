## 記憶類型概述

CrewAI 支持三種記憶類型：

| 記憶類型 | 說明 | 持續時間 | 應用場景 |
|---------|------|---------|---------|
| **短期記憶** | 當前任務執行過程中的上下文 | 單次執行 | 任務間數據傳遞 |
| **長期記憶** | 跨執行的經驗和學習 | 持久化存儲 | 學習和改進 |
| **實體記憶** | 關於特定實體的信息 | 持久化存儲 | 用戶資料、知識圖譜 |

### 記憶架構圖

## 短期記憶

短期記憶（Short-Term Memory）存儲當前任務執行過程中的上下文信息。

### 啟用短期記憶

```python
from crewai import Crew, Agent, Task, Process

# 創建 Crew 時啟用短期記憶
crew = Crew(
    agents=[agent1, agent2],
    tasks=[task1, task2],
    memory=True,  # 啟用記憶功能
    verbose=True
)
```

### 短期記憶工作原理

```python
# 範例：多任務協作中的短期記憶

from crewai import Agent, Task, Crew

# Agent 1: 研究員
researcher = Agent(
    role='研究員',
    goal='收集產品信息',
    backstory='你是專業的市場研究員',
    verbose=True
)

# Agent 2: 分析師
analyst = Agent(
    role='分析師',
    goal='分析研究數據',
    backstory='你是數據分析專家',
    verbose=True
)

# 任務 1: 研究
research_task = Task(
    description='研究智能手錶市場的前三大品牌',
    agent=researcher,
    expected_output='品牌列表和基本信息'
)

# 任務 2: 分析（會自動訪問任務 1 的結果）
analysis_task = Task(
    description='分析這些品牌的競爭優勢',
    agent=analyst,
    expected_output='競爭分析報告',
    context=[research_task]  # 顯式聲明依賴
)

# 啟用記憶的 Crew
crew = Crew(
    agents=[researcher, analyst],
    tasks=[research_task, analysis_task],
    memory=True,  # 啟用短期記憶
    verbose=True
)

result = crew.kickoff()
```

### 短期記憶的優勢

1. **自動上下文傳遞**：後續任務可以訪問前面任務的輸出
2. **減少重複**：Agent 不需要重新處理已有信息
3. **提高一致性**：確保所有 Agent 在相同的上下文中工作

## 長期記憶

長期記憶（Long-Term Memory）允許 Crew 在多次執行之間保持和學習信息。

### 啟用長期記憶

```python
from crewai import Crew

crew = Crew(
    agents=[agent1, agent2],
    tasks=[task1, task2],
    memory=True,
    long_term_memory=True,  # 啟用長期記憶
    verbose=True
)
```

### 長期記憶存儲

CrewAI 使用嵌入式數據庫（默認為 SQLite）存儲長期記憶。

```python
# 指定記憶存儲位置
crew = Crew(
    agents=[agent1, agent2],
    tasks=[task1, task2],
    memory=True,
    long_term_memory=True,
    memory_config={
        'provider': 'local',  # 或 'redis', 'postgresql'
        'storage_path': './memory_storage'
    },
    verbose=True
)
```

### 長期記憶實際應用

```python
# 範例：客戶服務 Agent 的學習機制

from crewai import Agent, Task, Crew

support_agent = Agent(
    role='客服專員',
    goal='提供優質的客戶支持',
    backstory='你是經驗豐富的客服人員，會從過去的案例中學習',
    verbose=True
)

# 第一次執行
def handle_customer_query(query):
    task = Task(
        description=f'回答客戶問題: {query}',
        agent=support_agent,
        expected_output='客戶回覆'
    )

    crew = Crew(
        agents=[support_agent],
        tasks=[task],
        memory=True,
        long_term_memory=True,  # 啟用長期記憶
        verbose=True
    )

    return crew.kickoff()

# 第一次查詢
result1 = handle_customer_query("如何重置密碼？")
print(result1)

# 第二次查詢（Agent 會記得類似的過往案例）
result2 = handle_customer_query("忘記密碼怎麼辦？")
print(result2)
```

### 長期記憶的應用場景

- **個性化服務**：記住用戶偏好和歷史互動
- **知識累積**：從過去的任務中學習最佳實踐
- **錯誤避免**：記住過去的錯誤，避免重複
- **效率提升**：重用過去的成功解決方案

## 實體記憶

實體記憶（Entity Memory）專門存儲關於特定實體（如用戶、產品、組織）的信息。

### 實體記憶配置

```python
from crewai import Crew

crew = Crew(
    agents=[agent1, agent2],
    tasks=[task1, task2],
    memory=True,
    entity_memory=True,  # 啟用實體記憶
    verbose=True
)
```

### 實體記憶實例

```python
# 範例：CRM 系統中的客戶記憶

from crewai import Agent, Task, Crew

# 銷售 Agent
sales_agent = Agent(
    role='銷售代表',
    goal='理解客戶需求並提供解決方案',
    backstory='你是經驗豐富的銷售專家，善於記住客戶細節',
    verbose=True
)

# 客戶互動 1
def interact_with_customer(customer_name, interaction):
    task = Task(
        description=f'''
        客戶: {customer_name}
        互動: {interaction}

        記錄客戶信息並提供適當回應。
        ''',
        agent=sales_agent,
        expected_output='回應和客戶資料更新'
    )

    crew = Crew(
        agents=[sales_agent],
        tasks=[task],
        memory=True,
        entity_memory=True,  # 實體記憶
        verbose=True
    )

    return crew.kickoff()

# 第一次互動
result1 = interact_with_customer(
    "張先生",
    "詢問企業級 AI 解決方案，公司規模 500 人，預算 100 萬"
)

# 第二次互動（Agent 會記得張先生的信息）
result2 = interact_with_customer(
    "張先生",
    "想了解實施時程"
)

# Agent 會記住張先生的公司規模和預算
```

## 上下文共享

在多 Agent 系統中，有效的上下文共享至關重要。

### 任務依賴和上下文傳遞

```python
from crewai import Agent, Task, Crew

# 創建多個 Agent
planner = Agent(
    role='項目規劃師',
    goal='制定項目計劃',
    backstory='你是專業的項目管理專家',
    verbose=True
)

developer = Agent(
    role='開發者',
    goal='實現項目功能',
    backstory='你是全棧開發工程師',
    verbose=True
)

tester = Agent(
    role='測試工程師',
    goal='確保質量',
    backstory='你是 QA 專家',
    verbose=True
)

# 定義任務鏈
plan_task = Task(
    description='為待辦事項應用制定開發計劃',
    agent=planner,
    expected_output='詳細的開發計劃'
)

dev_task = Task(
    description='根據計劃實現核心功能',
    agent=developer,
    expected_output='實現方案',
    context=[plan_task]  # 依賴規劃任務
)

test_task = Task(
    description='為實現的功能編寫測試',
    agent=tester,
    expected_output='測試計劃',
    context=[plan_task, dev_task]  # 依賴規劃和開發任務
)

# 執行
crew = Crew(
    agents=[planner, developer, tester],
    tasks=[plan_task, dev_task, test_task],
    memory=True,
    verbose=True
)

result = crew.kickoff()
```

### 記憶清理和管理

```python
# 清除特定 Crew 的記憶
def clear_crew_memory(crew_id):
    """清除指定 Crew 的記憶"""
    # CrewAI 提供的記憶管理 API
    from crewai.memory import MemoryManager

    manager = MemoryManager()
    manager.clear_memory(crew_id)

# 導出記憶數據
def export_memory(crew_id, output_path):
    """導出記憶數據"""
    from crewai.memory import MemoryManager

    manager = MemoryManager()
    memory_data = manager.export_memory(crew_id)

    import json
    with open(output_path, 'w') as f:
        json.dump(memory_data, f, indent=2)

# 導入記憶數據
def import_memory(crew_id, input_path):
    """導入記憶數據"""
    from crewai.memory import MemoryManager
    import json

    with open(input_path, 'r') as f:
        memory_data = json.load(f)

    manager = MemoryManager()
    manager.import_memory(crew_id, memory_data)
```

### 敏感信息處理

```python
# 過濾敏感信息
from crewai import Crew

def sanitize_memory(data):
    """清理敏感信息"""
    import re
    # 移除郵箱
    data = re.sub(r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b', '[EMAIL]', data)
    # 移除電話
    data = re.sub(r'\b\d{3}-\d{3}-\d{4}\b', '[PHONE]', data)
    # 移除信用卡號
    data = re.sub(r'\b\d{4}[-\s]?\d{4}[-\s]?\d{4}[-\s]?\d{4}\b', '[CARD]', data)
    return data

crew = Crew(
    agents=[agent],
    tasks=[task],
    memory=True,
    memory_config={
        'sanitizer': sanitize_memory  # 記憶清理函數
    }
)
```

### 2. 定期清理記憶

```python
import schedule
import time

def cleanup_old_memories():
    """清理 30 天前的記憶"""
    from crewai.memory import MemoryManager
    from datetime import datetime, timedelta

    manager = MemoryManager()
    cutoff_date = datetime.now() - timedelta(days=30)
    manager.delete_before(cutoff_date)

# 每週執行一次清理
schedule.every().sunday.at("02:00").do(cleanup_old_memories)

while True:
    schedule.run_pending()
    time.sleep(3600)
```

```python
def monitor_memory_usage(crew_id):
```

```python
def save_memory_snapshot(crew_id):
    """保存記憶快照"""
    from crewai.memory import MemoryManager

    manager = MemoryManager()
    snapshot_id = f"{crew_id}_{datetime.now().strftime('%Y%m%d_%H%M%S')}"
    manager.create_snapshot(crew_id, snapshot_id)

def restore_memory_snapshot(crew_id, snapshot_id):
```

```python
        tasks=[task],
        memory=True,
        long_term_memory=True,
        entity_memory=True,
        memory_config={
            'namespace': 'writing_assistant',
            'provider': 'chromadb'  # 使用向量數據庫
        }
    )

    return crew.kickoff()
```

## 總結

### 記憶系統關鍵要點

1. **短期記憶**：用於單次執行中的任務間數據傳遞
2. **長期記憶**：用於跨執行的學習和經驗累積
3. **實體記憶**：用於存儲特定實體的結構化信息
4. **合理使用**：根據實際需求選擇合適的記憶類型
5. **定期維護**：清理過期數據，優化存儲和檢索性能

### 性能優化建議

- 使用適當的數據庫（SQLite 適合小規模，PostgreSQL 適合大規模）
- 啟用索引加速查詢
- 定期清理過期記憶
- 使用向量數據庫進行語義搜索
- 為不同項目使用命名空間隔離

### 安全性建議

- 過濾敏感信息
- 實施訪問控制
- 加密敏感記憶數據
- 定期備份記憶數據
- 遵守數據隱私法規
